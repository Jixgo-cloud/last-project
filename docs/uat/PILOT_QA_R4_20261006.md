# รอบทดลองโดยคนจริง R4 — SmartCareer

เตรียมวันที่ 6 ตุลาคม 2026 ตรวจเว็บจริงและอ่านค่าที่บันทึกกลับแล้ว **ยังไม่ได้เก็บผลของผู้ทดลองจริง** ใช้บัญชี QA เดิมได้ เพราะงานและข้อสอบเป็นชุดใหม่ แยกจาก R1–R3 และไม่ได้ล้างประวัติเดิม

**สถานะล่าสุด:** เจ้าของอนุญาตให้ AI สวมบทผู้ทดลองแล้ว และดำเนิน R4 วันที่ 6 ตุลาคม 2026 เวลา 23:14–23:22 น. มีใบสมัคร 2 รายการ ผู้เข้าสอบ 2 ครั้ง คะแนนหลังตรวจ 100%/50% ทั้งสองใบสมัครกำลังพิจารณา ข้อบกพร่องหลังบันทึกคะแนนและรายชื่อทักษะบริษัทแก้และตรวจซ้ำผ่านแล้ว ดู [ผลแก้และตรวจซ้ำ](PILOT_R4_REVIEW_FIX_20261006.md) และ [ผลจำลองเดิม R4](PILOT_R4_SIMULATED_RESULT_20261006.md) ข้อมูลศูนย์และความพร้อมด้านล่างเป็นข้อมูลก่อนเริ่ม หากคนจริงจะสมัครและสอบตั้งแต่ต้น ต้องเตรียมชุดใหม่ก่อน

ใช้ [ตารางทดลอง 90 นาทีและรายการก่อนเริ่ม](PILOT_R4_SESSION_SCHEDULE.md) สำหรับนัดผู้สมัครสองคน บริษัทหนึ่งคน และผู้สังเกต แล้วดำเนินตามใบงานด้านล่าง

## เจ้าของเตรียมก่อนนัด

1. กำหนดรหัสผู้ทดลอง P01, P02 และ C01 พร้อมผู้สังเกตหนึ่งคน ใช้รหัสในแบบบันทึกแทนชื่อจริง
2. ให้ P01 ใช้ GitHub QA `Jixgo-cloud`, P02 ใช้ GitHub QA `BqnkZaa` (BADREE KAKOK), C01 ใช้ Google บริษัท QA ที่เจ้าของอนุญาต บัญชีบริษัทต้องแสดง Batriy Kakoh's Organization (UAT QA) เจ้าของจัดการรหัสผ่านหรือรหัสยืนยันเอง ไม่ส่งให้ผู้ทดลองหรือบันทึกในเอกสาร
3. จัดลำดับผู้สมัครแต่ละคนประมาณ 15–20 นาที บริษัทประมาณ 15–20 นาที แล้วให้ผู้สมัครกลับมาอ่านผลและแจ้งเตือนประมาณคนละ 5 นาที ช่วงบริษัทต้องรอจนผู้สมัครส่งคำตอบแล้ว
4. เปิด [แบบกรอกความคิดเห็น R4](PILOT_R4_FEEDBACK_FORM.html) ใหม่แยกคน หรือพิมพ์ PDF `output/pdf/SmartCareer_Pilot_R4_Worksheet_TH.pdf` ที่จัดเตรียมในเครื่อง จดวันเวลา อุปกรณ์ และเบราว์เซอร์
5. ก่อนเริ่มเปิดหน้างานและรายชื่อเฉพาะงาน ตรวจชื่อ R4 ให้ตรง หากมีข้อมูล R4 จากการทดลองก่อนแล้ว ให้บันทึกสถานะจริงและเตรียมรอบใหม่ก่อนรับผู้ทดลองชุดถัดไป ไม่ลบข้อมูลเพื่อทำให้กลับเป็นศูนย์

## ใบงานผู้สมัคร P01 / P02

ให้ทำตามลำดับโดยไม่บอกเฉลย หากต้องบอกทางให้ผู้สังเกตจดว่าช่วยตรงไหน

1. เข้า [SmartCareer](https://smartcareerplatform.vercel.app/login) ด้วย GitHub QA ที่เจ้าของจัดไว้ ตรวจชื่อบัญชีให้ตรงก่อนทำต่อ
2. เปิด [งาน R4](https://smartcareerplatform.vercel.app/jobs/b32d48ce-98f4-4aa6-bec3-edab67228f55) อ่านรายละเอียด ชื่อข้อสอบ เวลา และเกณฑ์ผ่าน แล้วอธิบายด้วยคำของตนว่างานนี้ให้ทำอะไร
3. กด **ยื่นใบสมัครผ่าน SmartCareer** กรอกข้อความสมัครว่า `QA R4 — ทดลองระบบตามใบงาน` พร้อมเหตุผลสั้น ๆ ของตน กด **ยืนยันการสมัคร** แล้วเปิด [ประวัติการสมัคร](https://smartcareerplatform.vercel.app/applications) ตรวจว่างานและข้อสอบเป็น R4 หากเว็บขอข้อมูลโปรไฟล์เพิ่ม ให้จดสิ่งที่ขอและให้เจ้าของบัญชียืนยันก่อนแก้
4. เตรียมตัวให้พร้อม แล้วกด **เริ่มทำแบบทดสอบทันที** จากใบสมัคร R4 เวลาจะเริ่มเมื่อหน้าข้อสอบโหลดสำเร็จ ไม่เปิดหน้าสอบเพียงเพื่อดูเล่นก่อนเริ่ม อ่านและตอบทั้งสองข้อด้วยตนเอง
5. กด **ส่งคำตอบและบันทึกคะแนน** บันทึกข้อความที่เห็นและเวลาที่ใช้ ก่อนบริษัทตรวจ คะแนนต้องยังไม่เปิดเผยตามการตั้งค่ารอบนี้ หากเกิดข้อผิดพลาด ให้เก็บข้อความและหน้าที่เกิด ไม่กดส่งซ้ำถี่ยิบ
6. หยุดรอบแรกไว้ ให้บริษัท QA ตรวจ เมื่อผู้สังเกตแจ้งว่าตรวจแล้ว กลับ [ประวัติการสมัคร](https://smartcareerplatform.vercel.app/applications) ดูผลของ R4 และอธิบายความหมายของคะแนนกับสถานะการคัดเลือกแยกกัน ผลสอบผ่านไม่ได้แปลว่ารับเข้าทำงาน
7. หลังบริษัทเปลี่ยนสถานะ QA เปิดกระดิ่ง อ่านแจ้งเตือน R4 แล้วเปิดใบสมัครให้ตรงงาน โหลดใหม่ตรวจว่าผลยังอยู่ หากหาไม่เจอให้บันทึกตามจริง
8. กรอกความคิดเห็นตามสิ่งที่ตนพบ ดาวน์โหลดคำตอบก่อนปิดแบบกรอก ผู้สังเกตไม่ตอบแทนผู้ทดลอง

รอบนี้ไม่ยกเลิกใบสมัคร ไม่สอบใหม่ ไม่เปลี่ยนผลเก่า และไม่ต้องสมัครบัญชีใหม่ หากผู้ทดลองต้องหยุดเพราะเวลาหรือปัญหา ให้จดเหตุและคงข้อมูลไว้

## ใบงานบริษัท C01

1. เข้า SmartCareer ด้วย Google บริษัท QA เปิด [ผู้สมัครเฉพาะงาน R4](https://smartcareerplatform.vercel.app/company/applications?jobId=b32d48ce-98f4-4aa6-bec3-edab67228f55) ตรวจชื่อ R4 และเฉพาะสองบัญชีที่เจ้าของจัดไว้ ตัวเลขจะขึ้นตามจำนวนที่สมัครจริง
2. อ่านใบสมัครและชื่อข้อสอบ ตรวจว่าคะแนนความเหมาะสม คะแนนสอบ และสถานะคัดเลือกเป็นคนละเรื่อง หากพบผู้สมัครอื่นให้หยุดรายการนั้นและแจ้งผู้สังเกต
3. เปิด [ข้อสอบบริษัท](https://smartcareerplatform.vercel.app/company/assessments) ค้นหา `PILOT-QA-R4-THEORY-20261006` กด **ตรวจผลและให้คะแนนผู้สมัคร** แล้วเปิด **ตรวจคำตอบและผลสอบ** ของผู้สมัคร QA ที่ส่งแล้ว
4. อ่านคำตอบ คะแนนดิบและคะแนนเต็ม ให้คะแนนตามผลจริงในช่อง **คะแนนที่ผู้ตรวจประเมิน (0-100%)** ไม่ใส่คะแนนสมมติเพื่อให้ผ่าน ใส่เหตุผลภายในบริษัท เช่น `QA R4 — ตรวจตามคำตอบที่ส่งจริง` แล้วกด **บันทึกคะแนนขั้นสุดท้าย** สำหรับแต่ละใบสมัคร อย่าแก้คำถามหรือเฉลยระหว่างรอบ
5. กลับรายชื่อเฉพาะงาน R4 เปลี่ยนสถานะเฉพาะผู้สมัคร QA เป็น **กำลังพิจารณา** เพื่อทดลองแจ้งเตือน ไม่มีการตัดสินรับเข้าทำงานจริงในใบงานนี้ แจ้งผู้สังเกตเมื่อบันทึกแล้ว
6. โหลดหน้าใหม่ ตรวจว่าคะแนนและสถานะคงอยู่ในงาน R4 กรอกความคิดเห็นและดาวน์โหลดคำตอบ ไม่เปลี่ยนผลของ R1–R3

คะแนนเต็ม 50: 50/50 = 100%, 25/50 = 50%, 0/50 = 0% ให้ใช้ผลที่เกิดขึ้นจริง การแจ้งเตือนในขั้นนี้ตรวจหลังเปลี่ยนสถานะ ไม่สมมติว่าการบันทึกคะแนนอย่างเดียวต้องส่งแจ้งเตือนด้วย เหตุผลภายในบริษัทไม่ใช่ข้อความแจ้งผู้สมัคร

## ผู้สังเกตและเกณฑ์บันทึก

- ก่อนเริ่ม ให้ผู้ทดลองอธิบายสิ่งที่คาดว่าจะเกิด จากนั้นปล่อยให้หาปุ่มเอง จดเวลาและคำพูดจริง
- **ทำเองได้** = ไม่ต้องบอกทาง, **ต้องช่วย** = จดสิ่งที่ช่วย, **ทำต่อไม่ได้** = จดจุดหยุด, **ยังไม่ลอง** = ไม่มีผล อย่าเปลี่ยนการทำได้เมื่อมีคนช่วยเป็นทำเองได้
- ใช้หนึ่งแบบบันทึกต่อคน กลับมาเติมผลหลังบริษัทตรวจในแบบของ P01/P02 ได้ เก็บคำตอบต้นฉบับไว้ในพื้นที่ส่วนตัว ไม่ส่งขึ้น GitHub แบบกรอกทำงานในเครื่อง ไม่ส่งข้อมูลไป SmartCareer และไม่บันทึกอัตโนมัติ
- จดบัญชี QA บทบาท วันเวลา อุปกรณ์ หน้าที่เปิด สิ่งที่คาด/เกิดจริง คะแนนดิบและเปอร์เซ็นต์เมื่อเปิดเผยแล้ว พร้อมหลักฐานเฉพาะปัญหาหากจำเป็น ไม่เก็บรหัสผ่าน คุกกี้ หรือข้อมูลผู้สมัครจริง
- หลังจบถามว่าเข้าใจสถานะและคะแนนหรือไม่ ขั้นตอนไหนหาไม่เจอ และอยากแก้จุดใดก่อน รวบรวมประเด็นซ้ำและสิ่งที่ทำให้หยุดก่อนตัดสินใจแก้รอบถัดไป
