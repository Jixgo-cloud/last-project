2. ตรวจไฟล์สำรองในโฟลเดอร์ส่วนตัวทั้งหมด **5 ชุดไฟล์** พบครบ 28 ตาราง ขนาดตรงกับ manifest ค่า SHA-256 ตรง และอ่านรายการใน archive ได้ ทั้งนี้บางชุดอาจเป็นสำเนาของข้อมูลรอบเดียวกัน ไม่ถือเป็นจุดกู้คืนต่างกันทั้งห้าชุด
3. อ่านข้อมูลจาก archive ในหน่วยความจำด้วย `pg_restore` แบบไม่เชื่อมต่อฐานข้อมูล ตรวจส่วนข้อมูลครบ 28 ตารางต่อไฟล์ และค้นรหัสงานแบบตรงกับค่าในคอลัมน์ ไม่พบแถวที่ตรงกับรหัสงานเดิมในทุกชุด ไม่มีการพิมพ์ข้อมูลส่วนบุคคลหรือค่าลับออกมา
4. สำรองเก่าสุดที่พบมีเวลาไทย **6 ตุลาคม 2026 02:38:24 น.** หลังเวลาที่พบเหตุแล้ว การค้นชื่อไฟล์ dump และสำรอง SQL ที่ระบุ SmartCareer ภายใต้ `D:/Workshop` ไม่พบไฟล์เก่ากว่านี้ ไม่ได้ตรวจไดรฟ์อื่นหรือไฟล์ชื่ออื่นทุกชนิด
