รายงานนี้เก็บผลรอบแรกของฉบับ `6666031` ไว้ ต่อมาแก้การติดตามรอบและทดสอบ ADM-041 ผ่านบนฉบับ `91f1ff0` แล้ว ดู [ผลตรวจซ้ำและทะเบียนล่าสุด](INGESTION_RUN_TRACKING_20261006.md) ไม่แก้ทับหลักฐานความล้มเหลวด้านล่าง

## สิ่งที่ยืนยันและแก้

- ตัวดึง Blognone, JobsDB และ JobThai เดิมเรียก `curl` ผ่านคำสั่งภายนอกแบบรอทั้งกระบวนการ เปลี่ยนเป็น HTTP ของ Node แบบ asynchronous มี timeout และขนาดตอบกลับจำกัด ไม่ต้องพึ่ง `curl` และไม่ยึดส่วนรับคำขออื่นของ API ระหว่างรอต้นทาง
- `Dockerfile.api` ไม่ได้ติดตั้ง curl แต่ Railway ใช้ Railpack ตามเอกสารการเผยแพร่เดิม การตรวจไฟล์ Docker จึงไม่ใช่หลักฐานว่า Railway ไม่มี curl จริง ไม่สรุปสาเหตุเซิร์ฟเวอร์จากไฟล์นี้เพียงอย่างเดียว
- ตรวจ HTML สาธารณะปัจจุบันของ Blognone พบข้อความ CSS ปนในชื่องาน แยกอ่านหัวข้อจริง ตัด style/script ออก และอ่านชื่อบริษัทแยกจากช่วงเงินเดือน
- ตรวจ JobThai พบชื่อบริษัทอยู่ใน `job-list-company-name-*` เดิมตัวเลือกหัวข้อซ้ำอ่านไม่ตรง เปลี่ยนเป็นชื่อบริษัทที่ระบุจริงและไม่รวมชื่อซ้ำจากหน้ามือถือ
- JSearch เดิมคืนรายการว่างเมื่อไม่มีคีย์หรือบริการปฏิเสธ ทำให้เหลือเพียงข้อความรวม เพิ่มเหตุแยกคีย์ไม่มี, HTTP 401/403, HTTP 429, ติดต่อไม่ได้ และตอบกลับไม่ครบ พร้อมตัดรายการไม่มีรหัส/ชื่องาน/บริษัท/ลิงก์ ไม่เก็บข้อความดิบที่อาจมีค่าลับ
- คงพฤติกรรมรักษางานเดิมเมื่อดึงไม่ได้ ไม่เพิ่มงานตัวอย่าง ไม่เปลี่ยนข้อมูลย้อนหลัง ไม่ข้าม HTTP 403 หรือระบบป้องกันของต้นทาง

## การตรวจในเครื่อง

- `npm run build`: ผ่านทั้ง shared, API และเว็บ
- `npm run lint`: ผ่าน ไม่มีข้อผิดพลาดหรือคำเตือน ESLint
- `npm test`: ผ่าน 50 รายการ (security 16 และ UAT 34) รวมกรณี transport ไม่พึ่ง curl, บริษัทไม่ใช่เงินเดือน/ชื่อซ้ำ, เหตุ JSearch ไม่เปิดเผยคีย์ และ HTTP ผิดพลาดไม่เพิ่มงาน
- ดึงสาธารณะจริงโดยไม่ต่อฐานข้อมูล: JobsDB 10 รายการและ JobThai 10 รายการ ชื่อ บริษัท และสถานที่เป็นข้อความที่ใช้ได้
- Blognone ตอบ HTTP 200 ในการอ่านครั้งแรก แต่รอบ live หลังแก้ตอบ HTTP 403 จึงไม่รับรองความพร้อมบริการจริงจากเครื่องนี้ ผลอ่าน HTML ที่เก็บจาก HTTP 200 ด้วย parser ฉบับแก้ได้ 5 รายการ เช่นชื่อ Mobile Developer ( Flutter or React Native ) และบริษัท NILECON THAILAND ไม่ใช่ช่วงเงินเดือน การอ่าน HTML ที่เก็บไว้ไม่เท่ากับผลนำเข้าปัจจุบันบนเว็บจริง
- ไม่มีการใช้คีย์ JSearch จริงหรือสร้างงานจากการตรวจในเครื่องนี้ การจำลองเหตุบริการใช้คีย์ QA ในหน่วยความจำและคืนค่าตัวแปรหลังทดสอบ
