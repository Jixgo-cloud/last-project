- ข้อสอบ `PILOT-QA-THEORY-20261006` แนบกับงาน มี 2 ข้อ ข้อละ 25 คะแนน เต็ม 50 ใช้เวลา 10 นาที เกณฑ์ผ่าน 70% เปิดเผยผลหลังบริษัทตรวจ ไม่มีการผูกกับทักษะจริง จึงไม่ตั้งใจใช้วัดความสามารถด้านโปรแกรม

## ลำดับทดลอง

1. ผู้สมัครแต่ละบัญชีเปิดงานที่ระบุ อ่านรายละเอียดและกดสมัคร โดยใช้ข้อความว่าเป็นการทดลองด้วยบัญชี QA
2. เปิดหน้า [ประวัติการสมัคร](https://smartcareerplatform.vercel.app/applications) ตรวจว่างานและข้อสอบที่ได้รับตรงกับรอบนี้
3. อ่านคำอธิบายและเวลาในใบสมัครให้พร้อมก่อนกดเริ่มทำแบบทดสอบ เมื่อเปิดหน้าข้อสอบ ระบบจะเริ่มหรือกลับเข้าสู่รอบสอบและจับเวลาอัตโนมัติ ไม่มีปุ่มเริ่มอีกชั้น เลือกคำตอบและใช้ปุ่มส่งข้อสอบตามหน้าจอ หลังส่งตรวจว่าสถานะบันทึกสำเร็จ ผลต้องยังไม่เปิดเผยจนบริษัทตรวจ
4. บริษัทเปิดงานรอบนี้แล้วดูผู้สมัคร ตรวจว่ารายการเป็นของงานนี้ ดูผลข้อสอบและบันทึกการตรวจตามปุ่มที่แสดง หากปรับคะแนนต้องระบุเหตุผลว่าเป็นการทดลอง
5. ผู้สมัครกลับมาดูผลและกระดิ่ง คะแนน 50/50 ต้องเท่ากับ 100% และ 25/50 เท่ากับ 50% การแจ้งผลและสิทธิ์เห็นคะแนนต้องตรงกับที่บริษัทบันทึก
6. บริษัทลองเปลี่ยนสถานะใบสมัคร QA และผู้สมัครตรวจข้อความที่ได้รับ หากทดลองรับเข้าทำงานจนถึง 2 คน งานควรปิดรับตามโควตา ขั้นตอนนี้อาจทำให้งานไม่พร้อมสำหรับรอบถัดไป จึงควรทำท้ายรอบ

ไม่เริ่มจับเวลาข้อสอบหรือส่งใบสมัครแทนผู้ทดลองในขั้นเตรียมนี้ เพื่อให้เริ่มรอบใหม่ได้จริง บริษัทที่ยังไม่รับรองไม่ถือว่าเป็นบริษัทรับรองเพียงเพราะเข้าสู่ระบบได้ รอบนี้ไม่ครอบคลุมการตรวจเอกสารจริงหรือการสมัครบัญชีใหม่

ตรวจเตรียมแล้ว: บริษัท Google เข้าสู่ระบบได้ ผู้สมัคร Jixgo-cloud และ BADREE KAKOK เข้าผ่าน GitHub ได้ เห็นงานใหม่และปุ่มสมัครที่ใช้งานได้ เปิดค่าข้อสอบที่บันทึกกลับมาตรวจได้ครบ งานมีใบสมัคร 0 และข้อสอบมีรอบสอบ 0 จึงพร้อมสำหรับเริ่มทดลอง ยังไม่ได้รับรองกระบวนการทั้งรอบว่าเสร็จหรือผ่าน
