# ตรวจงานนำเข้าฝั่งผู้ค้นหางาน — 6 ตุลาคม 2569

ต่อจากการนำเข้า JobsDB 10 และ Blognone 5 งาน ตรวจบนเว็บจริงด้วย Computer Use บัญชีผู้ดูแลเดิม ไม่เปลี่ยนเป็นบัญชีผู้สมัคร จึงไม่ใช้ผลนี้แทนคะแนนความเหมาะสมหรือการบันทึกงานของผู้สมัคร

## ข้อบกพร่องที่พบและแก้

รายละเอียดงาน Thai Agro Exchange แสดง Node.js และ PostgreSQL เป็นทักษะหลักพร้อมคะแนนขั้นต่ำ ทั้งที่ข้อความที่นำเข้าระบุเพียง Full Stack, AI และ cloud โค้ดสำรองของตัวอ่านทักษะเติม stack ตามชื่อตำแหน่งเมื่อไม่พบเทคโนโลยี ทำให้ทักษะและคอร์สแนะนำอาจผิดจากข้อความต้นทาง

แก้ตัวอ่านให้คืนรายการว่างเมื่อไม่พบชื่อเทคโนโลยี ลบการเติมทักษะสำเร็จรูปของ QA/Frontend/ตำแหน่งอื่น และกรองคำตอบ AI ให้มีหลักฐานในข้อความผ่านชื่อหรือชื่อเรียกที่กฎตรวจพบ เพิ่มกรณีตรวจไม่มีเทคโนโลยี เทคโนโลยีที่ระบุจริง AI เสนอทักษะที่ไม่ปรากฏ และบริการ AI ตอบว่าง/ขัดข้อง ไม่เปลี่ยนสูตรหรือคะแนนทักษะของผู้สมัคร

## แก้ข้อมูลเฉพาะรอบที่เพิ่งนำเข้า

สำรอง schema public ของ Supabase smartcareer-db ก่อนแก้: 29 ตาราง, 262604 bytes, archiveValidated=true และตรวจ SHA256 ตรง manifest เก็บนอก Git ที่ `D:/Workshop/SmartCareer-private-backups/2026-10-06T10-54-59-666Z/` สำรองนี้ยังไม่ผ่านการกู้ทดสอบ ไม่ได้กู้ทับฐานข้อมูลจริง

ตรวจงานทั้ง 15 กับไฟล์รอบนี้โดย source/externalId, URL, ชื่อ, บริษัท, description และเวลาสร้าง ต้องมีรายการตรงกันเพียงหนึ่งรายการ ไม่มี companyId และไม่มีใบสมัคร ก่อนแก้ตรวจซ้ำใน transaction แบบ Serializable และเก็บข้อมูลลิงก์เดิมนอก Git

พบ 9 งานที่มีเพียงคู่ทักษะสำเร็จรูป Node.js/PostgreSQL โดยไม่มีชื่อเหล่านี้ในข้อความ ลบเฉพาะลิงก์ทักษะที่ไม่รองรับ 18 ลิงก์ ตรวจหลังแก้เหลือ 0 ลิงก์ที่เข้าเงื่อนไข ไม่ลบประกาศ ไม่ลบทักษะหลัก ไม่แก้ข้อมูลผู้ใช้ ใบสมัคร หรือผลสอบ งานเก่าหรือทักษะอื่นนอกเงื่อนไขนี้ยังไม่ได้ตรวจย้อนทั้งหมด

หลักฐานในเครื่อง `outputs/local-jobs/skill-repair-preview.json` และ `skill-repair-applied.json` สคริปต์เฉพาะรอบและสำรองไม่ส่งขึ้น GitHub
