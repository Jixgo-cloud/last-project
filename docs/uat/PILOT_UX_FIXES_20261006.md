# ผลการแก้จุดใช้งานจากรอบจำลองผู้ทดลอง 6 ตุลาคม 2569

อ้างอิง [ข้อเสนอรอบจำลอง](PILOT_SIMULATED_FEEDBACK_20261006.md) รอบนี้เป็นการปรับและตรวจโดยผู้ช่วย ไม่ใช่ผลสำรวจของผู้ทดลองจริง ไม่สร้างใบสมัครหรือเปลี่ยนคะแนนและสถานะคัดเลือกเดิม

## สิ่งที่แก้

| ส่วน | พฤติกรรมหลังแก้ |
|---|---|
| ตรวจข้อสอบปรนัยของบริษัท | แสดงคำถาม คำตอบที่เลือก เฉลย และคะแนนรายข้อ เรียงตามรอบสอบ ไม่แสดงช่องโค้ดหรือคะแนน AI ที่ไม่ได้ใช้ ส่วน Coding ยังแสดงโค้ดและผล AI ตามเดิม |
| สถานะใบสมัคร | หน้าบริษัท ผู้สมัคร ประวัติสถานะที่ระบบสร้าง และป้ายสถานะในกระดิ่งใช้ชื่อสถานะตาม TH/EN ตัวเลือกจำไว้เมื่อเปลี่ยนหน้าและโหลดใหม่ ข้อความที่บริษัทเขียนเองคงเดิม การปรับนี้ยังไม่ใช่การแปลทั้งเว็บไซต์ |
| ความหมายของคะแนน | อธิบายแยกความเหมาะสมกับงาน คะแนนสอบ และผลคัดเลือก ไม่เปลี่ยนสูตรหรือคะแนนย้อนหลัง |
| คำแนะนำผลสอบ | ผลที่เปิดเผยแล้วมีคำแนะนำทั่วไปจากระบบและลิงก์คอร์ส ไม่แสดงเมื่อผลยังถูกซ่อนหรือรอตรวจ บันทึกเหตุผลตรวจและรหัสผู้ตรวจภายในบริษัทไม่ส่งให้ผู้สมัคร แม้เปิดเผยคะแนนแล้ว |
| เวลาคอร์ส | แก้ข้อมูลวิดีโอสองรายการที่ตรวจยืนยันจากข้อมูลหลักของ YouTube ระบบนำเข้าอ่านเวลาจากวิดีโอที่ตรงกันและพร้อมเล่น หากตรวจไม่ได้ไม่ใช้ค่าเดาจากรายการตั้งต้น |

## การตรวจอัตโนมัติ

สร้างทั้งโปรเจกต์และตรวจรูปแบบโค้ดผ่าน ชุดทดสอบผ่าน 82 ข้อ: ความปลอดภัย 16 และ UAT อัตโนมัติ 66 เพิ่มการตรวจที่ครอบคลุมคำตอบปรนัยและคะแนนศูนย์ การแยกข้อมูลบริษัทกับผู้สมัคร การซ่อนบันทึกภายในทุกนโยบาย คำแนะนำเมื่อผลถูกซ่อน สถานะสองภาษา และเวลาวิดีโอที่ผิดรายการ/ไม่พร้อม/ดึงไม่ได้

## การเผยแพร่และตรวจเว็บจริง

อยู่ระหว่างเผยแพร่และตรวจซ้ำ ผลสุดท้ายจะบันทึกเพิ่มหลังยืนยันฉบับ API และหน้าเว็บที่ใช้งานจริง

ทะเบียน UAT เดิมยังเป็น **ผ่าน 159 / ติดขัด 26 / ไม่ผ่าน 1** จาก 186 กรณี งานปรับความเข้าใจหน้าจอไม่ใช้เพิ่มจำนวนผ่านหรือปิดกรณีที่ยังไม่มีหลักฐาน โดยเฉพาะใบสมัครเก่าที่หาย บัญชีสมัครใหม่ บริษัทที่สอง และเอกสารรับรองที่ยังไม่พร้อม
