# ตารางทดลอง SmartCareer R5 สำหรับผู้ทดลองจริง

ใช้เวลาประมาณ **90 นาที** สำหรับผู้สมัคร 2 คน บริษัท 1 คน และผู้สังเกต 1 คน ใช้บัญชี QA เดิมกับ [งาน R5](https://smartcareerplatform.vercel.app/jobs/d0512c12-3b81-4b01-9dfd-09c4f7c292b5) โดยผู้สมัครทำก่อน บริษัทตรวจต่อ แล้วผู้สมัครกลับมาอ่านผล เจ้าของเลือกวันและเวลาเริ่มได้เอง ตารางนี้นับเวลาจากจุดเริ่มและยังไม่ได้เป็นการนัดหมายกับผู้ทดลอง

ใช้ [ใบงาน R5](PILOT_QA_R5_20261006.md) ควบคู่กับ [แบบกรอกความคิดเห็น R5](PILOT_R5_FEEDBACK_FORM.html) ผู้ทดลองแต่ละคนทำเอง ผู้สังเกตจดการช่วยและจุดที่หยุดตามจริง

**สถานะล่าสุด 7 ตุลาคม 2026:** R5 ใช้จำลองโดย AI ตามที่เจ้าของอนุญาตแล้ว มีใบสมัคร 2 รายการ รอบสอบ 2 ครั้ง คะแนน 100%/50% กำลังพิจารณาทั้งสองคน ดู [ผลจำลอง R5](PILOT_R5_SIMULATED_RESULT_20261007.md) ตารางนี้ยังเป็นแบบจัดเวลาสำหรับคนจริง ไม่ใช่เวลาที่ AI ใช้ หากจะสมัครและสอบใหม่ต้องจัดชุดใหม่เมื่อผู้ทดลองพร้อม คงข้อมูล R1–R5 และไม่สร้างรอบถัดไปอัตโนมัติ ไม่มีความคิดเห็นคนจริงในรอบนี้

เผื่อเวลาอีก 15 นาทีสำหรับเข้าสู่ระบบหรือปัญหาอุปกรณ์ได้ แต่ **เวลาสอบของแต่ละคนยังเป็น 10 นาที** ห้ามเปิดหน้าข้อสอบก่อนพร้อมหรือสัญญาว่าหยุดเวลาได้ ตารางไม่บังคับให้สอบผ่าน ผู้ทดลองตอบตามความเข้าใจของตน

## ผู้สังเกตใช้คำพูดอย่างไร

ก่อนแต่ละช่วงใช้ข้อความสั้น ๆ ว่า “ลองทำตามใบงานและบอกว่าคิดว่าจะเกิดอะไร ถ้าหาปุ่มไม่เจอหรือติดขัดให้บอกได้” ให้ผู้ทดลองหาปุ่มเองก่อน หากต้องช่วย ให้จดข้อความที่บอกและขั้นที่ช่วย

หลังจบถามทุกคนเหมือนกันสามข้อ: “คะแนนกับสถานะหมายถึงอะไร”, “ขั้นตอนไหนหาไม่เจอหรือใช้เวลานาน”, “อยากให้แก้จุดไหนก่อนและเพราะอะไร” จดคำตอบตามคำพูดของผู้ทดลอง ไม่เติมความเห็นแทน

**ทำเองได้** หมายถึงไม่ต้องบอกทาง; **ต้องช่วย** ให้จดสิ่งที่ช่วย; **ทำต่อไม่ได้** ให้จดจุดหยุด; **ยังไม่ลอง** ให้คงไว้เมื่อไม่มีการทดลอง ผลที่ทำได้หลังช่วยยังเป็น “ต้องช่วย”

## เก็บผลและจัดลำดับหลังทดลอง

ให้ P01 และ P02 เติมแบบเดิมหลังอ่านผลดาวน์โหลดอีกครั้ง เก็บฉบับช่วงแรกไว้ด้วย หากใช้ไฟล์ HTML ดาวน์โหลดก่อนปิด เพราะไม่มีการบันทึกอัตโนมัติ บริษัทกรอกขั้น 1–6 และเลือก “ไม่เกี่ยวข้อง” ในขั้น 7–8 เก็บไฟล์คำตอบและภาพเฉพาะปัญหาในพื้นที่ส่วนตัว ไม่ส่งขึ้น GitHub

| ลำดับจัดการ | ปัญหาที่เข้าเกณฑ์ |
|---|---|
| หยุดและแก้ก่อนทดลองต่อ | เข้าผิดบัญชี ข้อมูลข้ามบัญชี ส่งข้อมูลไม่สำเร็จ หรือคะแนนบันทึกไม่ตรง |
| แก้รอบถัดไปเป็นอันดับต้น | ผู้ทดลองไปต่อไม่ได้หรือหลายคนต้องช่วยในขั้นเดียวกัน แม้ข้อมูลบันทึกได้ |
| ปรับภายหลังตามผลซ้ำ | คำอธิบายหรือตำแหน่งปุ่มทำให้ลังเล แต่ยังทำต่อเองได้ |

ก่อนสรุปว่าเป็นข้อบกพร่อง ให้ตรวจเหตุและทำซ้ำกับข้อมูล QA อย่างปลอดภัย แยกปัญหาที่ระบบทำผิดออกจากข้อเสนอเรื่องการใช้งาน การเตรียมตารางและคำตอบของผู้ทดลองไม่เพิ่มจำนวนผ่าน UAT โดยอัตโนมัติ ต้องผูกผลกับกรณีเดิมและเก็บหลักฐานก่อนเปลี่ยนทะเบียน
