# ผลแก้ข้อความคะแนนและปุ่มดูผลสอบ SmartCareer

วันที่ 7 ตุลาคม 2026 แก้ข้อสังเกตจาก [การจำลอง R5](PILOT_R5_SIMULATED_RESULT_20261007.md) แล้วเผยแพร่และตรวจผ่านเว็บจริงด้วยบัญชี QA เดิม หน้าใบสมัครแสดง “รอตรวจ” เพียงครั้งเดียว และใช้ชื่อปุ่ม “ดูผลสอบ” สำหรับผลที่ส่งแล้ว คะแนน 100%/50% และสถานะกำลังพิจารณาของ R5 ยังคงเดิม

## สิ่งที่เปลี่ยน

| ส่วน | ก่อนแก้ | หลังแก้ |
|---|---|---|
| คะแนนในใบสมัครผู้สมัคร | ข้อสอบที่ยังไม่มีคะแนนสุดท้ายแสดงรอตรวจสองครั้ง และป้ายรอผลใช้สีเดียวกับไม่ผ่าน | แสดงรอตรวจครั้งเดียวในตำแหน่งคะแนน ไม่แสดงป้ายผ่านหรือไม่ผ่านจนมีคะแนน |
| คะแนนในรายชื่อและประวัติข้อสอบบริษัท | แสดงคำรอตรวจซ้ำในคะแนนและป้ายผล | แสดงรอตรวจในตำแหน่งคะแนนเพียงครั้งเดียว ป้ายผ่านหรือไม่ผ่านแสดงเมื่อมีคะแนน |
| ลิงก์ผลสอบจากใบสมัคร | “ดูผล / ทำแบบทดสอบอีกครั้ง” รวมสองการกระทำ | “ดูผลสอบ” เปิดหน้าผลเดิม ปุ่มสอบใหม่ยังอยู่ในหน้าผลตามสิทธิ์ |
| ลิงก์สำหรับข้อสอบที่ยังทำไม่จบ | ใช้ชื่อเดียวกับดูผล | แสดง “ทำแบบทดสอบต่อ” สำหรับรอบกำลังทำ |
| ใบสมัครที่ปิดแล้ว | “ดูผลสอบที่ส่งแล้ว” | คงข้อความและเงื่อนไขเดิม ไม่เพิ่มสิทธิ์สอบใหม่ |

แก้เฉพาะหน้าผู้สมัครและหน้ารายชื่อบริษัท ไม่มีการแก้สูตรคะแนน ช่องทางเข้าสู่ระบบ สิทธิ์สอบ หรือข้อมูลใบสมัคร
