# ผลตรวจ CAN-011 ตามเกณฑ์เดิม — 7 ตุลาคม 2026

**CAN-011 รอบล่าสุดผ่าน** ผลการทำงานปัจจุบันรวม **ผ่าน 185 / ติดขัด 0 / ไม่ผ่าน 0 / ข้ามตามขอบเขต 1** จาก 186 กรณี การกู้ใบสมัคร QUOTA เดิม **ยังไม่สำเร็จ** และติดตามแยกเป็น **REC-001** ไม่ใช้ผลนี้รับรองว่าข้อมูลเดิมกลับมาแล้วหรือว่าผ่านครบ 186 กรณี

## เกณฑ์ที่ตรวจ

ตรวจจากไฟล์ต้นทางที่ใช้สร้าง UAT (`tmp/uat-author/build-uat.mjs` บรรทัด 71) กรณี CAN-011 ชื่อ “รายละเอียดใบสมัครและลำดับสถานะ” กำหนดให้บริษัทเปลี่ยนสถานะอย่างน้อยหนึ่งครั้ง ผู้สมัครเปิด `/applications` ตรวจชื่อบริษัท งาน วันสมัคร สถานะปัจจุบันและลำดับขั้นที่แสดง แล้วโหลดใหม่ ข้อมูลต้องตรงใบสมัครและการเปลี่ยนจากบริษัท เกณฑ์นี้ไม่ได้กำหนดการกู้รายการที่ลบไปแล้ว

เทียบกับรายการที่บันทึกจาก Excel เดิม `outputs/smartcareer-uat-retest-20261005/SmartCareer_Manual_UAT_All_Roles.xlsx.inspect.ndjson` แล้ว ขั้นตอนและผลที่คาดหวังตรงกัน ไฟล์ Excel/PDF ก่อนรอบนี้เก็บเป็นหลักฐานประวัติ ไม่ได้แก้ย้อนหลังหรือสร้างใหม่ในรอบนี้ ผลล่าสุดอยู่ในทะเบียน `outputs/uat-execution-20261005/results.json` และรายงานนี้

ก่อนรอบนี้รายงานนำผลการทำงานปัจจุบันกับการกู้ข้อมูลเดิมมารวมเป็น CAN-011 ไม่ผ่าน รอบนี้แยกสองเรื่องให้ตรงเกณฑ์ต้นฉบับ ไม่เปลี่ยนขั้นตอนหรือผลที่คาดหวังเพื่อให้ผ่าน และเก็บผลไม่ผ่านเดิมพร้อมหลักฐานไว้ครบ

## ผลตรวจเว็บจริง

ใช้ใบสมัคร QA รอบใหม่ที่สร้างผ่านฟอร์มจริงในรอบแก้ไขก่อนหน้า บริษัท QA เปลี่ยนสถานะผ่านหน้า Pipeline จน Accepted ไม่มีการสร้างผลรับเข้าทำงานย้อนหลังด้วยฐานข้อมูล API ฉบับที่ตรวจ `fec210ebbe85488bf5754a3676b944b64c444f3a` สุขภาพ ok และฐานข้อมูล connected

การป้องกันลบงานที่มีใบสมัคร การสมัครพร้อมลบ และการปิดรับเมื่อครบโควตาผ่านในรอบแก้ไขก่อนหน้า ดู [รายงานการแก้](CAN_011_RETENTION_FIX_20261007.md) รอบนี้ไม่แก้โค้ดแอปเพิ่ม ไม่ลบหรือสร้างข้อมูลทดสอบเพิ่ม และไม่รันการคัดกรองข้อมูลทั้งระบบจริง

หลักฐานก่อนและหลังโหลดใหม่ รายการตรวจหน้าจอ การเทียบข้อมูลแบบอ่านอย่างเดียว และภาพที่เห็นจริงอยู่ใน `outputs/uat-can011-acceptance-20261007/` เก็บเฉพาะในเครื่อง ผลและภาพเก่าคงไว้ ไม่ส่งภาพหรือข้อมูลบัญชีขึ้น GitHub

## เหตุที่ยังไม่ปิด

**REC-001: ข้อมูล QA QUOTA เดิมสูญหายก่อนฉบับป้องกันการลบ** ยังไม่มีงานและใบสมัครเดิมในฐานข้อมูล ไม่พบในสำรอง 13 ชุดที่ตรวจ ไม่สร้างรายการเดิมย้อนหลังจากการเดา ต้องมีแหล่งข้อมูลที่เก็บรายการนั้นไว้ก่อนหายจึงดำเนินการกู้ต่อได้ ดู [ทะเบียนเหตุที่ยังไม่ปิด](OPEN_RECOVERY_INCIDENTS.md)
