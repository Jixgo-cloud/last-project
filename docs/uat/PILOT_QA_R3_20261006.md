## วิธีเริ่มรอบ

1. ผู้สังเกตจดวันเวลาและบัญชีที่ใช้ใน [ใบงานผู้ทดลอง](PILOT_PARTICIPANT_GUIDE.md) ให้ผู้ทดลองทำเองและจดขั้นที่ต้องช่วย
2. ผู้สมัครเข้าด้วย GitHub เปิดลิงก์งาน R3 อ่านคำอธิบายและกดสมัครด้วยข้อความระบุ QA
3. เปิดประวัติการสมัคร ตรวจงานและข้อสอบชื่อ R3 เตรียมพร้อมก่อนกดเริ่ม **เวลา 10 นาทีเริ่มเมื่อหน้าข้อสอบโหลดสำเร็จ**
4. ตอบและส่งตามหน้าจอ ตรวจว่าบันทึกสำเร็จและผลยังรอตรวจ ไม่ใช้การกลับเข้าข้อสอบเพื่ออ่านอย่างเดียวก่อนพร้อม
5. บริษัทเปิดใบสมัครเฉพาะ R3 เปิดตรวจผลและบันทึกพร้อมเหตุผล QA คงคะแนนตามคำตอบจริง จากนั้นผู้สมัครตรวจคะแนนและกระดิ่ง
6. เปรียบเทียบ 50/50 = 100%, 25/50 = 50%, 0/50 = 0% การทดลองเปลี่ยนสถานะและรับครบโควตาทำเป็นขั้นท้ายกับใบสมัคร QA เท่านั้น

ยังไม่ได้สมัคร เริ่มสอบ ส่งคำตอบ ตรวจคะแนน หรือเปลี่ยนสถานะ R3 การสร้างชุดใหม่ไม่เพิ่มผลผ่านครบกระบวนการโดยอัตโนมัติ บริษัทเดิมยังไม่ส่งเอกสารรับรอง ไม่ใช้รอบนี้เป็นผลทดสอบรับรองบริษัทหรือสมัครบัญชีใหม่
