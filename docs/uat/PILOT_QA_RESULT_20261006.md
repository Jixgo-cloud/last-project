## ข้อสังเกต

### PILOT-001 — ลิงก์ผลสอบหลังใบสมัครถูกปฏิเสธ

ความรุนแรง: ปานกลาง ยืนยันบนเว็บจริงด้วย BADREE เฉพาะงานรอบนี้

หลังส่งข้อสอบและบริษัทตรวจคะแนน 50% แล้ว บริษัทเปลี่ยนใบสมัครเป็นปฏิเสธ ผู้สมัครยังเห็นคะแนนในหน้าใบสมัครและลิงก์ “ดูผล / ทำแบบทดสอบอีกครั้ง” แต่เปิดลิงก์แล้วพบ “ยังเปิดแบบทดสอบนี้ไม่ได้” และ “แบบทดสอบนี้เปิดให้เฉพาะผู้สมัครที่บริษัทมอบหมายเท่านั้น”

สาเหตุจากโค้ด: หน้า `apps/web/app/applications/page.tsx` ยังแสดงลิงก์ตามการมีผลสอบ ส่วน `assertCandidateAccess` ใน `apps/api/src/assessments/assessments.service.ts` ไม่นับใบสมัครสถานะ REJECTED หรือ CANCELLED ในสิทธิ์เข้าข้อสอบ ทั้งการดูข้อมูลข้อสอบและการเริ่มสอบใช้การตรวจสิทธิ์นี้

ควรแยกสิทธิ์ดูผลที่ตนส่งสำเร็จแล้วออกจากสิทธิ์เริ่มสอบใหม่ โดยยังคงข้อจำกัดการเปิดเผยผลและการแยกบัญชี หากยังไม่รองรับการดูผล อย่างน้อยต้องไม่แสดงลิงก์ที่กดใช้งานไม่ได้ รอบนี้ไม่ได้แก้โค้ดส่วนนี้หรือเปลี่ยนสถานะกลับเพื่อให้ผ่าน

หน้าข้อสอบเริ่มหรือกลับเข้าสู่รอบสอบและจับเวลาเมื่อโหลดข้อสอบสำเร็จ ไม่มีปุ่มเริ่มอีกชั้น แก้คู่มือรอบทดลองให้ผู้ทดลองอ่านเงื่อนไขและเตรียมตัวก่อนเปิดหน้าทำข้อสอบแล้ว

ผลรอบนี้เป็นการทดสอบตามเส้นทางที่ระบุ ไม่เปลี่ยนหลักฐานหรือผล UAT ย้อนหลัง และไม่รับรองการสมัครบัญชีใหม่ เอกสารรับรอง การแยกข้อมูลสองบริษัท การซูม 200% หรืออุปกรณ์จริง

การปิดรับอัตโนมัติเมื่อครบ 2 คนไม่ได้ใช้กรณีนี้ทดสอบ เพราะเลือกผลการทดลองเป็นรับ 1 บัญชีและปฏิเสธ 1 บัญชี งานจึงยังมีโควตาเหลือ การทดลองรอบต่อไปควรสร้างชุดใหม่หรือกำหนดรอบให้ชัด อย่าเริ่มสอบซ้ำโดยไม่บันทึกว่ากำลังทดสอบอะไร
