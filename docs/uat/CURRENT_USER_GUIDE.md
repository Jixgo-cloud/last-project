# คู่มือใช้งานและเตรียมทดสอบ SmartCareer ปัจจุบัน

ปรับปรุง 7 ตุลาคม 2026 อ้างอิงหน้าจอและโค้ดใน `apps/web/app` คู่มือนี้ใช้ร่วมกับ [การทดสอบช่องทางสมัครและเข้าสู่ระบบ](AUTH_PROVIDER_POLICY.md) เอกสารและ PDF รุ่นเก่าที่ระบุสมัครด้วยอีเมล รหัสผ่านของผู้สมัคร/บริษัท หรือเก็บรหัสเข้าสู่ระบบใน LocalStorage เป็นข้อมูลย้อนหลัง

ผลการทำงานล่าสุดผ่าน 185 ข้ามตามขอบเขต 1 จาก 186 กรณี CAN-011 ตรวจข้อมูลและขั้นตอนใบสมัครหลังโหลดใหม่ตรงข้อมูลที่บริษัทบันทึกแล้ว การกู้ใบสมัคร QA เก่าที่หายยังไม่สำเร็จ แยกเป็น REC-001 ดู [ผลตรวจล่าสุด](CAN_011_ACCEPTANCE_RETEST_20261007.md) และ [เหตุที่ยังไม่ปิด](OPEN_RECOVERY_INCIDENTS.md)

เอกสารรับรองเดิมของบริษัทดาวน์โหลดผ่านลิงก์ที่ตรวจสิทธิ์เจ้าของแล้ว ผู้ดูแลคัดกรองคอร์สต้องเปิดรายงานและเลือกแต่ละคอร์สก่อนยืนยันลบ ระบบตรวจซ้ำเฉพาะรหัสที่เลือก การลบผ่านเว็บกู้คืนไม่ได้ ตรวจชื่อรายการก่อนยืนยัน ดู [ผลตรวจรอบล่าสุด](UAT_REMAINING_RETEST_20261007.md)

ตรวจลบงาน ข้อสอบ และคอร์ส QA บนเว็บจริงวันที่ 7 ตุลาคมผ่านแล้ว หลังผู้ใช้ยืนยันเฉพาะรายการและสำรองข้อมูล งาน/ข้อสอบ QA ไม่มีใบสมัครหรือผู้สอบ คอร์สสมมติไม่มีทักษะผูก การลบคอร์สตรวจซ้ำเฉพาะรหัสที่เลือก รายการอื่นและประวัติสมัคร/สอบคงเดิม ไม่ใช้การลบทั้งหมดเพื่อให้ผลทดสอบผ่าน

วันที่ 7 ตุลาคมทดสอบเอกสารสมมติที่ระบุ QA TEST ONLY บนเว็บจริงตามที่ผู้ใช้อนุญาต ผ่านการส่งสองแท็บ ดาวน์โหลด ปฏิเสธพร้อมแจ้งเหตุ ส่งใหม่ การตรวจพร้อมกันสองแท็บ การแบ่งหน้า และอนุมัติ บริษัท QA แสดง Verified หลังโหลดใหม่และแจ้งเตือนอนุมัติหนึ่งรายการ ประวัติเดิมคงอยู่ ชื่อและคำอธิบายบริษัทระบุเป็นข้อมูลทดสอบชัดเจน ผลนี้ไม่ใช่การรับรองนิติบุคคลจริง บัญชีบริษัทจริงยังต้องใช้เอกสารที่ถูกต้องและให้ผู้รับผิดชอบตรวจ

## การเข้าสู่ระบบ

GEN-010 การตรวจเชื่อมครั้งแรกของบัญชีอีเมลเดิมที่ยังไม่ผูก GitHub/Google ถูกข้ามตามขอบเขตที่ผู้ใช้ปรับวันที่ 7 ตุลาคม 2026 ไม่ต้องเตรียมบัญชีชนิดนี้ การสมัครใหม่และเข้าสู่ระบบตามผู้ให้บริการยังอยู่ในขอบเขตทดสอบ

ผู้สมัครใช้ GitHub เท่านั้น บริษัทใช้ Google เท่านั้น ผู้ดูแลใช้อีเมลและรหัสผ่านในส่วนที่ระบุ Admin บัญชีเดิมยังมีข้อมูลอยู่ วันที่ 7 ตุลาคมตรวจผู้สมัคร GitHub และบริษัท Google QA ใหม่ที่ผู้ใช้เตรียมผ่านแล้วแบบผู้ใช้ช่วยดำเนินการในขั้นตอนสมัครครั้งแรก ตรวจผลหลังสมัครและเข้าสู่ผู้ให้บริการทั้งสองซ้ำด้วยเครื่องมือแล้ว กลับข้อมูลเดิมโดยไม่เพิ่มบัญชีหรือบริษัทซ้ำ การสร้างบริษัทไม่ทำให้ได้รับตรารับรองอัตโนมัติ

เมนูบัญชีแสดงบทบาทและช่องทางไปหน้าของแต่ละบทบาท ปุ่ม TH/EN เปลี่ยนข้อความในเมนูนำทาง ไม่ได้แปลเนื้อหาทุกหน้า การแจ้งเตือนอยู่ที่ปุ่มกระดิ่งสำหรับบัญชีที่เข้าสู่ระบบ

## ผู้เยี่ยมชม

- หน้าหลัก `/`: วิเคราะห์ชื่อ GitHub สาธารณะเพื่อดูข้อมูลที่มีอยู่จริง การดูตรงนี้ไม่ใช่การบันทึกผลงานลงบัญชี
- งาน `/jobs`: ค้นหาชื่อตำแหน่ง ทักษะ สถานที่ เลือกแหล่งงาน สายงาน งานทางไกล และลำดับรายการ ตัวกรองแหล่งงานกับสายงานเลื่อนด้านข้างได้บนมือถือ
- รายละเอียดงาน: อ่านเงื่อนไขและทักษะที่ต้องการ งานจากแหล่งภายนอกอาจพาไปสมัครที่ต้นทาง งานของบริษัทใน SmartCareer สมัครผ่านบัญชีผู้สมัคร
- คอร์ส `/courses`: ค้นหาและกรองคอร์ส แล้วเปิดลิงก์ไปเรียนที่ผู้ให้บริการ การเรียนและชำระเงินเป็นขั้นตอนของต้นทาง

## ผู้สมัคร

| หน้า | สิ่งที่ทำได้ |
|---|---|
| โปรไฟล์ `/profile` | แก้ไขข้อมูลและเป้าหมายสายงาน ดูหลักฐานผลงาน คะแนนทักษะ และเหรียญ กดซิงค์ผลงาน GitHub เพื่ออัปเดตหลักฐาน ชื่อ GitHub ที่ผูกแล้วเปลี่ยนเป็นบัญชีอื่นไม่ได้ |
| งาน `/jobs` | ค้นหางาน ดูคะแนนความเหมาะสมและเงื่อนไขทักษะ บันทึกงานที่สนใจ เปิดรายละเอียดแล้วสมัครงานที่เปิดรับ |
| การสมัคร `/applications` | ดูสถานะ หมายเหตุ ประวัติ และข้อสอบที่ได้รับมอบหมาย ยกเลิกใบสมัครผ่านกล่องยืนยันตามเงื่อนไขของหน้าจอ |
| ข้อสอบ `/assessments` | เลือกข้อสอบสาธารณะที่เปิดและพร้อมใช้งาน ข้อสอบบริษัทเริ่มได้เมื่อได้รับมอบหมาย ไม่ใช่ทุกบัญชีที่เปิดลิงก์แล้วทำได้ |
| หน้าทำข้อสอบ | อ่านคำอธิบายและเวลาก่อนเปิดข้อสอบ เมื่อหน้าข้อสอบโหลดสำเร็จจะเริ่มหรือกลับเข้าสู่รอบสอบและจับเวลาอัตโนมัติ ไม่มีปุ่มเริ่มแยกอีกชั้น Theory เลือกคำตอบ; Coding แก้โค้ด เลือกภาษา รันเพื่อตรวจ แล้วส่งตามปุ่มที่แสดง |
| ผลสอบและคอร์ส | ผลยังไม่ตรวจจะแสดงรอตรวจ ข้อสอบบริษัทอาจเปิดเผยทันที หลังตรวจ หรือไม่เปิดเผยตามที่บริษัทกำหนด คอร์สช่วยค้นหาสิ่งที่ควรเรียนเพิ่มเติม |

การรันโค้ดเพื่อตรวจไม่เท่ากับการส่งข้อสอบสำเร็จ ให้ตรวจข้อความและหน้าผลหลังส่งทุกครั้ง คะแนนดิบกับเปอร์เซ็นต์เป็นคนละหน่วย เช่น 25/50 เท่ากับ 50%

ในประวัติการสมัคร ลิงก์ **ดูผลสอบ** ใช้เปิดผลของรอบที่ส่งแล้วโดยไม่เริ่มจับเวลารอบใหม่ หากข้อสอบยังทำไม่จบ ลิงก์แสดง **ทำแบบทดสอบต่อ** ปุ่ม **สอบใหม่อีกครั้ง (Retake)** อยู่ในหน้าผลตามสิทธิ์ของบัญชีและงาน เมื่อยังไม่มีคะแนนที่เปิดเผยได้ หน้าคะแนนแสดง **รอตรวจ** เพียงครั้งเดียวและยังไม่แสดงป้ายผ่านหรือไม่ผ่าน ดู [ผลตรวจการแก้ข้อความ](PILOT_R5_LABEL_FIX_20261007.md)

ผู้สมัครที่ถูกปฏิเสธหรือยกเลิกใบสมัครยังเปิดดูผลสอบที่ส่งแล้วของตนได้ตามเงื่อนไขเปิดเผยคะแนนของบริษัท ลิงก์แสดงว่า “ดูผลสอบที่ส่งแล้ว” และไม่ให้เริ่มสอบใหม่จากใบสมัครที่ปิดแล้ว การดูผลเก่าไม่เริ่มจับเวลา ข้อสอบที่บริษัทปิดใช้งานก็ยังดูผลที่ส่งแล้วได้ แต่สอบใหม่ไม่ได้

## บริษัท

| หน้า | สิ่งที่ทำได้ |
|---|---|
| แดชบอร์ด `/company/dashboard` | ดูสรุปและลิงก์ไปงาน ผู้สมัคร และข้อมูลของบริษัทตนเอง |
| ข้อมูลบริษัท `/company/profile` | แก้ไขรายละเอียดและโลโก้ ดูสถานะการรับรอง ส่งข้อมูลและเอกสารของบริษัทที่เจ้าของอนุญาต การเข้าสู่ระบบด้วย Google ไม่ทำให้ได้รับการรับรองทันที |
| งาน `/company/jobs` และ `/company/jobs/new` | สร้างหรือแก้งาน ระบุทักษะ จำนวนรับ และข้อสอบที่พร้อมใช้งาน เปิดหรือปิดรับตามปุ่มที่แสดง เปิดรายชื่อผู้สมัครจากงานนั้นเพื่อดูเฉพาะงานที่เลือก |
| ผู้สมัคร `/company/applications` | กรองและดูใบสมัคร เปลี่ยนสถานะ มอบหมายข้อสอบพร้อมหมายเหตุ ดูหลักฐาน ประเมิน และส่งออก CSV ลิงก์ที่มี `jobId` จำกัดรายการและ CSV ให้เฉพาะงานนั้น |
| ข้อสอบ `/company/assessments` | สร้าง Theory หรือ Coding ค้นหา เปิด–ปิดข้อสอบ เลือกรูปแบบเปิดเผยผล ดูผู้เข้าสอบ ตรวจและปรับคะแนนพร้อมเหตุผลตามสิทธิ์และข้อจำกัดของข้อสอบ |

เวลาข้อสอบบริษัทต่ำสุด 10 นาที ข้อสอบปิดหรือเนื้อหาไม่พร้อมจะใช้แนบงานหรือมอบหมายไม่ได้ ขั้นตอนสัมภาษณ์และเสนองานเป็นการบันทึกสถานะในเว็บ ไม่ใช่การจองปฏิทินหรือส่งสัญญาจ้าง

งานบริษัทที่มีประวัติใบสมัครแล้วจะลบไม่ได้ แม้ใบสมัครถูกยกเลิก ให้ใช้ **ปิดรับสมัคร** เพื่อเก็บประวัติไว้ ปุ่มลบจะแสดงเหตุผล และระบบตรวจซ้ำก่อนลบด้วย งานไม่มีประวัติใบสมัครยังลบได้หลังยืนยันตามปกติ ทดสอบงาน QA รับครบ 1/1 แล้วปิดรับอัตโนมัติและประวัติยังอยู่เมื่อวันที่ 7 ตุลาคม ดู [ผลการตรวจ](CAN_011_RETENTION_FIX_20261007.md)

## ผู้ดูแลระบบ

| หน้า | สิ่งที่ทำได้ |
|---|---|
| แดชบอร์ด `/admin/dashboard` | ดูภาพรวมและสถานะที่ระบบแสดง |
| ผู้ใช้ `/admin/users` | ดูรายชื่อ ค้นหา และกรองบทบาท ไม่ใช้หน้านี้เปลี่ยนบทบาทหรือลบบัญชี เพราะไม่มีปุ่มดังกล่าว |
| ทักษะ `/admin/skills` | จัดการรายการทักษะตามฟอร์มและปุ่มที่แสดง |
| ข้อสอบ `/admin/assessments` | จัดการข้อสอบและเนื้อหา ตรวจผลและคะแนนตามสิทธิ์ เวลาต่ำสุด 5 นาที |
| รับรองบริษัท `/admin/verifications` | กรองคำขอ เปิดเอกสาร และบันทึกผลพร้อมเหตุผล ผู้รับผิดชอบต้องตรวจเอกสารจริงก่อนตัดสิน |
| นำเข้าและคัดกรอง `/admin/ingestion` | ตั้งค่าที่หน้าจอรองรับ ดูโควตาและประวัติ ทดลองแหล่งข้อมูลทีละแหล่งด้วยจำนวนต่ำสุด ตรวจตัวอย่างก่อนการคัดกรองจริง |

การนำเข้าจากแหล่งภายนอกอาจล้มเหลวหรือได้เพียงบางรายการ ต้องอ่านผลและประวัติจริง ไม่ถือว่าปุ่มกดได้แปลว่าข้อมูลเข้าครบ การลบจริงต้องแยกรายการ QA ได้แน่นอนและยืนยันรายการก่อนดำเนินการ

JobsDB และ Blognone รองรับการนำเข้าไฟล์จากหน้าประกาศที่เปิดอ่านได้ผ่านส่วน “นำเข้างานที่ดึงจากเครื่อง” ผู้ดูแลเลือกไฟล์ ตรวจตัวอย่าง แล้วกดยืนยัน ระบบตรวจงานซ้ำและเก็บประวัติแยกเป็น `JOBSDB_LOCAL_FILE`/`BLOGNONE_LOCAL_FILE` ดู [วิธีดึงและนำเข้าไฟล์](LOCAL_JOB_SCRAPING_20261006.md) วิธีนี้ยังต้องมีการเปิดอ่านหน้า ไม่ใช่การแก้ให้รอบอัตโนมัติบน Railway ที่ได้ 403 ทำงานสำเร็จแล้ว

## การบันทึกผลทดสอบ

ใช้ผลผ่าน ไม่ผ่าน หรือติดขัดตามสิ่งที่ตรวจจริง บันทึกหน้าที่ทดสอบ บทบาท ขนาดหน้าจอ รหัสฉบับ API และเหตุที่ติดขัด เก็บหลักฐานเดิมไว้ ผลจากฐานข้อมูลแยกไม่ใช้แทนผลสมัครผ่าน GitHub/Google จริง

การจำลองหน้าจอมือถือไม่ใช่การทดสอบบนอุปกรณ์จริง และการลดขนาดหน้าจอไม่ใช้แทนการซูมเบราว์เซอร์ 200% วันที่ 7 ตุลาคมผู้ใช้ตั้งซูมจริง 200% ใน INB แล้วตรวจแป้นพิมพ์และหน้าจอครบสามบทบาท แก้เมนูเกินจอและปุ่มซิงค์ GitHub ถูกตัดแล้วตรวจซ้ำผ่าน เมนูบัญชีและรายการแจ้งเตือนเลื่อนภายในจอได้ ปุ่มโปรไฟล์ขึ้นบรรทัดใหม่ในพื้นที่แคบ ตัวกรองงานอยู่ในแถวเลื่อนของตน ใช้ Tab และ Enter เลือกได้ ผลล่าสุดผ่าน 185 ติดขัด 0 ไม่ผ่าน 0 ข้าม 1 (GEN-010) หลังตรวจ CAN-011 ตามเกณฑ์เดิม การกู้ข้อมูล QA เก่ายังไม่สำเร็จ ติดตาม REC-001 แยกจากผล UAT ดู [ผลตรวจล่าสุด](CAN_011_ACCEPTANCE_RETEST_20261007.md) และ [เหตุที่ยังไม่ปิด](OPEN_RECOVERY_INCIDENTS.md)
