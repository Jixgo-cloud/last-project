# ทบทวนกรณี UAT ที่เหลือ — 6 ตุลาคม 2026

ตรวจซ้ำรอบ R3 ด้วยสองบัญชี QA เดิมแล้ว สมัคร → สอบ → ตรวจ → เปิดผล → สถานะและกระดิ่ง ผ่านตามขอบเขต คะแนน 100%/50% ตรงกันและรอบสอบไม่เพิ่มเมื่อเปิดผล/โหลดใหม่ ดู [ผล R3](PILOT_QA_R3_RESULT_20261006.md) จำนวน UAT คงเดิม เพราะเป็นการตรวจซ้ำกรณีที่ผ่านแล้ว

ทะเบียน 186 กรณี ผลล่าสุด: **ผ่าน 159 ติดขัด 26 ไม่ผ่าน 1** เพิ่ม GEN-029 หลังตรวจกระดิ่งว่างบนเว็บจริงครบผู้สมัคร บริษัท และผู้ดูแล ดู [ผลและชุดทดลอง R3](PILOT_QA_R3_20261006.md) เพิ่ม CAN-037 และ ADM-050 จาก Manual UI จำลองข้อขัดข้องในระบบแยกตามแผน พร้อมแก้ข้อความรันโค้ดไม่พร้อมและตรวจซ้ำ ดู [ผลตรวจส่วนที่ทำต่อได้](UAT_AVAILABLE_CONTINUATION_20261006.md) ไม่อ้างว่าเกิดบริการขัดข้องบนเว็บจริง ส่วน Blognone ดึงตรงจาก Railway บน API 988223a เวลา 20:47:44 เพิ่มจริง 8 พบเดิม 5 ผิดพลาด 0 รอบซ้ำเวลา 20:48:58 เพิ่ม 0 พบเดิม 13 ผิดพลาด 0 งานเดิมคงอยู่และข้อมูลตรงต้นทางครบ 13 งาน JobsDB ผ่านอยู่แล้ว ดู [ผลแก้และตรวจบน Railway](DIRECT_RAILWAY_SCRAPING_20261006.md) ตัวเลขนี้ยังไม่ใช่การรับรองทั้งโครงการ ไม่เปลี่ยนกรณีใบสมัครที่หายหรือกรณีสมัครบัญชีใหม่ที่พักไว้

ก่อนรอบนี้ผ่าน 154 ติดขัด 31 ไม่ผ่าน 1 หลังแก้ JSearch; หลังแก้ติดตามรอบก่อนตรวจ JSearch ผ่าน 153 ติดขัด 32 ไม่ผ่าน 1; ก่อนแก้ติดตามรอบผ่าน 152 ติดขัด 32 ไม่ผ่าน 2 หลักฐานแต่ละรอบยังเก็บไว้ ดู [ผลตรวจต่อหลังพักการกู้ใบสมัคร](UAT_CONTINUATION_AFTER_RECOVERY_20261006.md), [ผลตรวจนำเข้า 4 แหล่ง](INGESTION_RETEST_20261006.md), [ผลแก้ติดตามรอบนำเข้า](INGESTION_RUN_TRACKING_20261006.md) และ [ผลตรวจ JSearch](INGESTION_PROVIDER_ACCESS_20261006.md)

## ตรวจเพิ่มเติมบนเว็บจริง 6 ตุลาคม 2026

GEN-027 ตรวจซ้ำผ่านแล้ว: กด “เริ่มเรียนคอร์สนี้” ของ Python in 100 Seconds ที่ /courses พบแท็บใหม่ที่เกิดจากการคลิก และชื่อหน้า YouTube ตรงวิดีโอ ไม่ใช้การเปิด URL โดยตรงแทนการกดปุ่ม เก็บผลติดขัดเดิมก่อนปรับทะเบียน

ส่วนคลิกภายนอกของ GEN-029 ตรวจซ้ำด้วย BADREE บนหน้าผล PILOT แล้ว: เปิดกระดิ่ง คลิกหัวเรื่องนอกกล่อง กล่องปิดและปุ่มกลับเป็น collapsed เปิดอีกครั้งแล้วกด Escape กล่องปิดและคืน focus ที่ปุ่มกระดิ่ง ผ่านส่วนนี้โดยไม่เปลี่ยนรายการแจ้งเตือน บัญชีมีรายการแจ้งเตือนแล้ว จึงไม่ได้จำลองหน้าไม่มีรายการในรอบนี้ กรณีเต็ม “กระดิ่งเมื่อไม่มีรายการ” ยังไม่เปลี่ยนเป็นผ่านจากผลบางส่วน ทะเบียนและหลักฐานย้อนหลังยังเก็บไว้

ใบงานสำหรับผู้ทดลองและแบบจดข้อเสนอแนะอยู่ที่ [ใบงานผู้ทดลอง](PILOT_PARTICIPANT_GUIDE.md) แยกการอ่านผล PILOT เดิมออกจากรอบสมัครและสอบใหม่ที่ต้องเตรียมชุดงานใหม่

## ข้อผิดพลาดย้อนหลังที่ยังปิดไม่ได้

ADM-041 ปิดแล้ว: หลังแก้ติดตามรอบบน API `91f1ff0` หน้าเว็บติดตามรอบเดิมหลังโหลดใหม่และเปิดอีกแท็บได้ จบรอบแสดงผลเอง เพิ่ม 15 งาน พบเดิม 10 ผิดพลาด 0 รวม 25 งาน รอบใหม่พบเดิม 25 เพิ่ม 0 ผิดพลาด 0 ไม่มีงานเพิ่มซ้ำ เก็บผลไม่ผ่านบนฉบับ `6666031` ไว้เป็นประวัติ ดู [ผลแก้และตรวจซ้ำ](INGESTION_RUN_TRACKING_20261006.md)

CAN-011: ใบสมัคร QA ของงาน QUOTA หายไปก่อนแก้การล้างงานปิดรับแล้ว การแก้ปัญหาการล้างข้อมูลได้รับการตรวจแยก แต่ไม่สามารถกู้ใบสมัครเดิมผ่านหน้าเว็บ ต้องตรวจสำรองก่อนเกิดเหตุและให้เจ้าของพิจารณาการกู้ที่เหมาะสม ห้ามกู้ทับฐานข้อมูลจริงเพื่อให้กรณีนี้ผ่าน และยังไม่เปลี่ยนผลไม่ผ่านย้อนหลัง

ตรวจแหล่งสำรองต่อวันที่ 6 ตุลาคม 2026 แล้ว: สำรองในเครื่องที่พบทั้งหมดเกิดหลังเวลาพบเหตุและไม่มีรหัสงาน QUOTA เดิม Supabase smartcareer-db เป็น Free Plan ไม่มี Scheduled backups หรือจุด PITR ให้เลือกจากหน้าที่ตรวจ จึงยังไม่มีแหล่งข้อมูลเดิมให้กู้ คงผลไม่ผ่าน ดู [ผลตรวจความพร้อมกู้ CAN-011](CAN_011_RECOVERY_REVIEW_20261006.md)

ผลย้อนหลังก่อนแก้ตัวดึงตรงจาก Railway: JSearch ADM-038 ผ่านแล้วหลังเพิ่มเวลารอและแก้ลำดับคีย์ บน API/Web 5bbb34d รอบแรกเพิ่ม 10 พบเดิม 5 ผิดพลาด 0 รอบใหม่เพิ่ม 1 พบเดิม 14 ผิดพลาด 0 งานสาธารณะรวม 24 ข้อมูลครบและรหัส/ลิงก์ไม่ซ้ำ โหลดใหม่ติดตามรอบเดิมได้ ขณะนั้น JobsDB/Blognone ดึงตรงจาก Railway ยังได้ 403 แต่ช่องทางนำเข้าไฟล์จากหน้าที่อ่านได้ผ่านแล้ว: เพิ่ม JobsDB 10 งาน Blognone 5 งาน ส่งไฟล์เดิมในรอบใหม่เพิ่ม 0 ทั้งสองแหล่ง ดู [ผลตรวจนำเข้าไฟล์](LOCAL_JOB_SCRAPING_20261006.md) ไม่ต้องรอชื่อผู้ติดต่อ สถาบัน หรืออีเมลเพื่อใช้ช่องทางนี้ และไม่แปลงผลการนำเข้าไฟล์เป็นผ่านของ ADM-039–040 ที่ระบุการดึงตรงจากเซิร์ฟเวอร์ ผลผ่านการดึงตรงล่าสุดแสดงไว้ต้นเอกสาร

## การปรับปรุงรอบนี้

ตรวจทักษะงานเก่าต่อหลังนำเข้าไฟล์: ตรวจงานภายนอกเก่า 147 งาน แก้ชุดทักษะสำเร็จรูปที่ไม่มีหลักฐานใน 45 งาน รวม 95 ลิงก์ สำรองก่อนแต่ละรอบและตรวจงานอื่นคงเดิม ทักษะที่เหลือ 493 ลิงก์มีหลักฐานชื่อ/ชื่อเรียกในข้อความที่บันทึกไว้ คงงานที่มีใบสมัคร 1 งานไว้ ดู [ผลตรวจงานเก่า](OLDER_JOB_SKILL_REVIEW_20261006.md) ผลนี้ไม่ใช่การเปิดประกาศต้นทางทุกงานใหม่หรือการแก้คะแนนผู้สมัครย้อนหลัง และไม่เพิ่มผลผ่านของทะเบียน 186 กรณีโดยอัตโนมัติ

- แก้ตัวเลือกเรียงงานและหัวหน้าบริษัทที่ล้นจอขนาด 320 พิกเซล
- กระดิ่งรองรับการคลิกภายนอกและ Escape โดยคืนตำแหน่งแป้นพิมพ์ที่ปุ่มกระดิ่ง
- หน้างานอธิบายแหล่งงานตามข้อมูลที่แสดงจริง และหน้าสมัครอธิบายว่าต้องกดซิงค์ GitHub ในโปรไฟล์
- เพิ่ม [คู่มือปัจจุบัน](CURRENT_USER_GUIDE.md) และติดป้ายเอกสารเดิมว่าเป็นข้อมูลย้อนหลัง PDF เดิมยังเป็นหลักฐานรุ่นเก่า

ผลตรวจหน้าจอและรุ่นที่เผยแพร่เก็บในรายงานการดำเนินงานแยก การตรวจที่ขนาด 320/390 พิกเซลเป็นการตรวจการจัดวางในเบราว์เซอร์ ไม่รับรองอุปกรณ์จริงหรือการซูม 200% และไม่ครอบคลุมข้อสอบทุกชุดหรือทุกสถานะข้อมูล

## เตรียมรอบ R3 และปิดกระดิ่งว่าง

GEN-029 ตรวจเพิ่มเติมบนบัญชีบริษัท QA ที่ไม่มีรายการจริง คลิกเมาส์บริเวณนอกกล่องปิดได้ กด Escape ปิดและคืน focus รวมกับหลักฐานผู้สมัครและผู้ดูแลบนเว็บจริงครบสามบทบาท ไม่ล้างแจ้งเตือน ไม่ใช้ผลจำลองแทนเว็บจริง ประวัติติดขัดเดิมยังอยู่ในทะเบียน ผลล่าสุด 159 / 26 / 1

[ชุด R3](PILOT_QA_R3_20261006.md) สร้างและตรวจกลับแล้ว มีงานเปิดรับ 2 บัญชี ข้อสอบ Theory 2 ข้อ เต็ม 50 เวลา 10 นาที เปิดผลหลังตรวจ ใบสมัครและรอบสอบเป็นศูนย์ ยังไม่ได้เริ่มกระบวนการ R3 และไม่เพิ่มผลผ่านเพียงเพราะเตรียมข้อมูล รอบดึงงานเที่ยงคืนหลังแก้ยังไม่ถึงเวลาในการตรวจรอบนี้
