# ทบทวนกรณี UAT ที่เหลือ — 6 ตุลาคม 2026

ทะเบียนย้อนหลังมี 186 กรณี: ผ่าน 151 ติดขัด 34 ไม่ผ่าน 1 ตัวเลขนี้ไม่ใช่การรับรองเว็บปัจจุบันทั้งโครงการ และยังรักษาหลักฐานเดิมไว้ การตรวจรอบนี้เน้นหน้าจอเล็ก ข้อความ และคู่มือ ไม่ทำการสมัครบัญชีใหม่ตามที่ผู้ใช้ขอพักไว้

## กรณีติดขัดและเงื่อนไขที่จะตรวจต่อได้

| กลุ่ม | กรณี | สิ่งที่ต้องมีหรือข้อจำกัด |
|---|---|---|
| บัญชีใหม่ (พักไว้) | GEN-006, GEN-007, GEN-015, CAN-005 | บัญชี QA GitHub/Google ที่ยังไม่เคยสมัคร สำหรับสมัครใหม่และหน้าไม่มีข้อมูล |
| ขั้นตอนเดิมเปลี่ยนแล้ว | GEN-010, GEN-011, CAN-002 | ปรับเป็นตรวจการเข้าสู่ระบบตามผู้ให้บริการและการคงบัญชีเดิม ผู้สมัครใช้ GitHub บริษัทใช้ Google ไม่มีการสมัครด้วยอีเมลหรือผูก GitHub ครั้งแรกผ่านฟอร์มเดิม |
| บัญชีผู้ดูแล | GEN-012 | ต้องทดสอบรหัสผ่านผิดแล้วเข้าสู่ระบบสำเร็จด้วยบัญชี QA ผู้ดูแล ไม่เดารหัสผ่าน |
| การควบคุมเบราว์เซอร์ | GEN-027, GEN-029, E2E-013 | ตรวจแท็บคอร์สภายนอก การปิดกระดิ่งเมื่อคลิกภายนอก และซูมจริง 200% แยกกัน การเปลี่ยนขนาดหน้าจอไม่ใช่การซูม |
| การรับรองบริษัท | COM-009–012, ADM-027–033, E2E-001, E2E-011 | เอกสาร QA ที่เจ้าของอนุญาต คำขอครบจำนวนตามกรณี และผู้มีสิทธิ์ตัดสิน ไม่ใช้เอกสารหรือคำขอของคนจริงเพื่อให้ผ่าน |
| ลบข้อมูล | COM-020, COM-051, ADM-049 | ระบุรายการ QA และตรวจผลกระทบก่อนลบ การล้างคอร์สที่ปะปนข้อมูลจริงยังคงติดขัด |
| บริการภายนอก | CAN-037, ADM-038–041, ADM-050 | ตรวจผลรอบปัจจุบันของผู้ให้บริการ และจำลองความขัดข้องในสภาพแวดล้อมแยก ไม่ทำให้เว็บจริงล่มเพื่อทดสอบ |
| การแยกบริษัท | E2E-009 | ต้องมีบัญชีบริษัท QA อีกบัญชีที่อนุญาตให้ใช้งาน |

GEN-008 และ GEN-009 แม้มีผลผ่านย้อนหลัง ก็เป็นการตรวจฟอร์มสมัครเดิมที่ไม่มีแล้ว ต้องอ้างอิง [นโยบายช่องทางเข้าสู่ระบบ](AUTH_PROVIDER_POLICY.md) สำหรับรอบใหม่ ไม่แปลงผลเก่าเป็นผ่านโดยอัตโนมัติ

## ข้อผิดพลาดย้อนหลังที่ยังปิดไม่ได้

CAN-011: ใบสมัคร QA ของงาน QUOTA หายไปก่อนแก้การล้างงานปิดรับแล้ว การแก้ปัญหาการล้างข้อมูลได้รับการตรวจแยก แต่ไม่สามารถกู้ใบสมัครเดิมผ่านหน้าเว็บ ต้องตรวจสำรองก่อนเกิดเหตุและให้เจ้าของพิจารณาการกู้ที่เหมาะสม ห้ามกู้ทับฐานข้อมูลจริงเพื่อให้กรณีนี้ผ่าน และยังไม่เปลี่ยนผลไม่ผ่านย้อนหลัง

## การปรับปรุงรอบนี้

- แก้ตัวเลือกเรียงงานและหัวหน้าบริษัทที่ล้นจอขนาด 320 พิกเซล
- กระดิ่งรองรับการคลิกภายนอกและ Escape โดยคืนตำแหน่งแป้นพิมพ์ที่ปุ่มกระดิ่ง
- หน้างานอธิบายแหล่งงานตามข้อมูลที่แสดงจริง และหน้าสมัครอธิบายว่าต้องกดซิงค์ GitHub ในโปรไฟล์
- เพิ่ม [คู่มือปัจจุบัน](CURRENT_USER_GUIDE.md) และติดป้ายเอกสารเดิมว่าเป็นข้อมูลย้อนหลัง PDF เดิมยังเป็นหลักฐานรุ่นเก่า

ผลตรวจหน้าจอและรุ่นที่เผยแพร่เก็บในรายงานการดำเนินงานแยก การตรวจที่ขนาด 320/390 พิกเซลเป็นการตรวจการจัดวางในเบราว์เซอร์ ไม่รับรองอุปกรณ์จริงหรือการซูม 200% และไม่ครอบคลุมข้อสอบทุกชุดหรือทุกสถานะข้อมูล
