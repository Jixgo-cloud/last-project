  3. กด ยื่นใบสมัครผ่าน SmartCareer ใส่ข้อความ QA R4 — ทดลองระบบตามใบงาน พร้อมเหตุผลสั้น ๆ กด ยืนยันการสมัคร เปิด ประวัติการสมัคร ตรวจชื่องานและข้อสอบ R4
  4. เมื่อพร้อม กด เริ่มทำแบบทดสอบทันที จากใบสมัคร R4 เวลาจะเริ่มเมื่อหน้าข้อสอบโหลดสำเร็จ อ่านและตอบทั้งสองข้อด้วยตนเอง
  5. กด ส่งคำตอบและบันทึกคะแนน จดข้อความที่เห็น ก่อนบริษัทตรวจ คะแนนต้องยังไม่เปิดเผย หยุดรอบแรกไว้และแจ้งผู้สังเกต
  6. เมื่อบริษัทตรวจแล้ว กลับประวัติการสมัคร อ่านผล R4 อธิบายคะแนนกับสถานะคัดเลือกแยกกัน ผลสอบผ่านไม่ได้แปลว่ารับเข้าทำงาน
  7. หลังบริษัทเปลี่ยนสถานะ QA เปิดกระดิ่ง อ่านแจ้งเตือน R4 และเปิดใบสมัครให้ตรงงาน โหลดใหม่ดูว่าผลยังอยู่

SMARTCAREER • R4 • ใบงานบริษัท C01 และผู้สังเกต

ตรวจผลและติดตามสิ่งที่ผู้ทดลองพบ

บริษัททดลองหลังผู้สมัครส่งคำตอบแล้ว ใช้ Google บริษัท QA ที่เจ้าของอนุญาต ต้องแสดง Batriy Kakoh's Organization (UAT QA)
เปิดรายชื่อเฉพาะงาน R4 • เปิดข้อสอบบริษัท
  1. เปิดรายชื่อเฉพาะงาน R4 ตรวจว่าใบสมัครเป็นสองบัญชี QA ที่จัดไว้ จำนวนต้องตรงกับผู้สมัครที่สมัครจริง หากมีผู้อื่นให้หยุดรายการนั้น
  2. อ่านใบสมัครและชื่อข้อสอบ แยกคะแนนความเหมาะสม คะแนนสอบ และสถานะคัดเลือกให้ได้
  3. เปิดข้อสอบบริษัท ค้นหา PILOT-QA-R4-THEORY-20261006 กด ตรวจผลและให้คะแนนผู้สมัคร แล้วกด ตรวจคำตอบและผลสอบ ของผู้สมัครที่ส่งแล้ว
  4. อ่านคำตอบ คะแนนดิบและคะแนนเต็ม ให้คะแนนตามจริงในช่อง คะแนนที่ผู้ตรวจประเมิน (0-100%) ใส่เหตุผลภายในบริษัท เช่น QA R4 — ตรวจตามคำตอบที่ส่งจริง กด บันทึกคะแนนขั้นสุดท้าย ทีละคน ไม่แก้คำถามระหว่างรอบ
  5. กลับรายชื่อ R4 เปลี่ยนสถานะเฉพาะผู้สมัคร QA เป็น กำลังพิจารณา เพื่อทดลองแจ้งเตือน แจ้งผู้สังเกตเมื่อบันทึกแล้ว รอบนี้ไม่มีการตัดสินรับเข้าทำงานจริง
  6. โหลดใหม่ ตรวจคะแนนและสถานะคงอยู่ในงาน R4 กรอกความคิดเห็นหน้า 3 และดาวน์โหลดคำตอบ ไม่เปลี่ยนผล R1–R3

ผู้สังเกตเตรียมและจดอย่างไร

กำหนด P01, P02, C01 ใช้งานทีละคน ผู้สมัครประมาณคนละ 15–20 นาที บริษัท 15–20 นาที แล้วให้ผู้สมัครกลับมาอ่านผลคนละ 5 นาที เปิดแบบกรอกแยกคน

ให้ผู้ทดลองอธิบายสิ่งที่คาดว่าจะเกิดแล้วหาปุ่มเอง ทำเองได้ = ไม่ต้องบอกทาง; ต้องช่วย = จดสิ่งที่ช่วย; ทำต่อไม่ได้ = จดจุดหยุด; ยังไม่ลอง = ไม่มีผล ไม่ตอบความคิดเห็นแทนผู้ทดลอง

บันทึกคะแนนตามจริง 50/50 = 100%, 25/50 = 50%, 0/50 = 0% แจ้งเตือนตรวจหลังเปลี่ยนสถานะ ไม่สมมติว่าบันทึกคะแนนอย่างเดียวต้องส่งแจ้งเตือน เหตุผลภายในบริษัทไม่ใช่ข้อความแจ้งผู้สมัคร

ตอนเตรียม: ใบสมัคร 0 รายการ ผู้เข้าสอบ 0 ครั้ง ไม่ใช่ผลของผู้ทดลองจริง ทะเบียน UAT ยังผ่าน 159 / ติดขัด 26 / ไม่ผ่าน 1 รวม 186 กรณี
