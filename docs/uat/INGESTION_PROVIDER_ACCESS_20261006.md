# ตรวจการเชื่อมต่อแหล่งงานเพิ่มเติม — 6 ตุลาคม 2026

ผลทะเบียนยังเป็นผ่าน 153 ติดขัด 32 ไม่ผ่าน 1 จาก 186 กรณี การเรียกผู้ให้บริการสำเร็จจากเครื่องพัฒนาไม่ใช่ผลผ่านการนำเข้าบน Railway และยังไม่เปลี่ยน ADM-038–040 เป็นผ่าน

## JSearch — ADM-038

- ทดสอบคีย์เดิมใน `apps/api/.env` ด้วยคำขออ่าน `/search` หนึ่งครั้งไปยัง `https://jsearch.p.rapidapi.com` โดยไม่เขียนฐานข้อมูล ได้ HTTP 200 และรายการ 10 งาน บันทึกเฉพาะสถานะและจำนวน ไม่แสดงหรือเก็บคีย์ในผลตรวจ
- พบโค้ดเลือก `RAPIDAPI_KEY` ก่อน `JSEARCH_API_KEY` จึงแก้ให้คีย์เฉพาะ JSearch มีลำดับก่อน ตัดช่องว่างทั้งสองค่า และใช้คีย์ทั่วไปเมื่อไม่มีคีย์เฉพาะหรือคีย์เฉพาะมีแต่ช่องว่าง
- เพิ่มการตรวจอัตโนมัติว่าคีย์ทั่วไปไม่ทับคีย์เฉพาะ และกรณีไม่มีคีย์ไม่เรียกผู้ให้บริการ ยังคงการตรวจ 401/403/429 ว่าไม่มีข้อความหรือคีย์จากผู้ให้บริการหลุดออกไปและไม่สร้างงานตัวอย่าง
- ต้องตั้ง `JSEARCH_API_KEY` ใน soothing-love → production → @smartcareer/api บน Railway โดยใช้คีย์เดิมที่ทดสอบได้ ผู้ใช้กรอกและบันทึกเอง ไม่ส่งคีย์ในแชต ไม่ต้องสร้างหรือซื้อคีย์ใหม่ในขั้นนี้
- หลังเผยแพร่ต้องทดสอบผ่านหน้าผู้ดูแล: เริ่มรอบ ตรวจผลจริง จำนวนเพิ่ม/ซ้ำ/ผิดพลาด และข้อมูลแหล่งงาน จากนั้นเริ่มรอบใหม่เพื่อตรวจรายการซ้ำ คงโควตาเดิม 15 จนมีเหตุให้เปลี่ยน

## JobsDB — ADM-039

ตรวจซ้ำผ่านหน้าผู้ดูแลบน API `91f1ff0` เวลา 16:23:50 น. ได้ `SOURCE_HTTP_403` เพิ่ม 0 ซ้ำ 0 ผิดพลาด 1 หน้าแสดงผลสิ้นสุดเองและไม่เปลี่ยนโควตา 30 ช่องทางทางการของ SEEK รองรับ JobsDB ประเทศไทย แต่ต้องขอสิทธิ์และผ่านกระบวนการเชื่อมต่อ API เอกสารที่ตรวจอธิบายการลงประกาศและขั้นตอนสมัครงาน ไม่ได้ยืนยันว่ามีบริการดึงประกาศสาธารณะทั้งหมดให้ SmartCareer ใช้แทนตัวอ่านหน้าเว็บได้ทันที

อ้างอิง [ขั้นตอนเชื่อมต่อ SEEK API](https://developer.seek.com/introduction) และ [การยืนยันสิทธิ์](https://developer.seek.com/auth)

ข้อความสำหรับเจ้าของโครงการนำไปสอบถาม ยังไม่ได้ส่งหรือตอบรับข้อตกลง:

> SmartCareer ต้องการแสดงตำแหน่งงานเทคโนโลยีในประเทศไทยจาก JobsDB พร้อมชื่อบริษัทและลิงก์กลับไปสมัครที่ต้นทาง มี API หรือ feed สำหรับอ่านประกาศสาธารณะที่อนุญาตให้ใช้เพื่อจุดประสงค์นี้หรือไม่? กรุณาระบุสิทธิ์ที่ต้องขอ ข้อมูลที่แสดงได้ อัตราเรียก วิธีดูแลประกาศที่ปิดแล้ว และค่าใช้จ่าย หาก SEEK API รองรับเฉพาะประกาศของบริษัทที่มีความสัมพันธ์กับ partner กรุณายืนยันขอบเขตดังกล่าวด้วย

## Blognone — ADM-040

ตรวจซ้ำผ่านหน้าผู้ดูแลบน API `91f1ff0` เวลา 16:24:22 น. ได้ `SOURCE_HTTP_403` เพิ่ม 0 ซ้ำ 0 ผิดพลาด 1 หน้าแสดงผลสิ้นสุดเองและไม่เปลี่ยนโควตา 15 การเปิดเว็บไซต์ Jobs ด้วยเครื่องมือค้นคว้ารอบนี้ก็ได้ 403 จึงยังไม่มีหลักฐานว่าปรับตัวอ่านหน้าเว็บแล้วจะใช้ได้จากเซิร์ฟเวอร์จริง หน้าติดต่อทางการระบุช่องทางติดต่อทีมงาน แต่ไม่ยืนยัน API/feed สำหรับ Blognone Jobs ส่วน RSS ที่ลิงก์จากเว็บข่าวเป็น `www.blognone.com/atom.xml` ซึ่งไม่ใช่หลักฐานว่าเป็น feed ประกาศงาน

อ้างอิง [หน้าติดต่อ Blognone](https://www.blognone.com/contact) ไม่ตีความใบอนุญาตเนื้อหาเว็บข่าวว่าครอบคลุมสิทธิ์เข้าถึงประกาศงานทุกส่วนโดยอัตโนมัติ

ข้อความสำหรับเจ้าของโครงการนำไปสอบถาม ยังไม่ได้ส่ง:

> SmartCareer ต้องการแสดงประกาศงานเทคโนโลยีจาก Blognone Jobs พร้อมเครดิตและลิงก์กลับต้นทาง การอ่านหน้าค้นหาจาก Railway ปัจจุบันได้รับ HTTP 403 มี API/feed หรือช่องทางเชื่อมต่อสำหรับเซิร์ฟเวอร์ที่อนุญาตหรือไม่? กรุณาระบุเงื่อนไขการใช้ข้อมูล อัตราเรียก และวิธีติดตามประกาศปิดรับ หากต้องอนุญาตการเชื่อมต่อเพิ่มเติม กรุณาแจ้งขั้นตอน

## ขอบเขตผลตรวจ

โค้ดแก้เลือกคีย์ผ่าน `npm run build`, `npm run lint` และ `npm test` รวม 54 กรณี (ความปลอดภัย 16, UAT 38) ก่อน push การเผยแพร่และผลนำเข้า JSearch บนเว็บจริงยังต้องตรวจต่อหลังตั้งค่า ไม่ใช้ผลตรวจในเครื่องแทนผลดังกล่าว

ไม่ใช้การเปลี่ยน IP/proxy หรือปิดการตรวจ TLS เพื่อหลบการปฏิเสธคำขอ ไม่เปลี่ยนแหล่งงานอื่นให้แสดงว่าเป็น JobsDB/Blognone และไม่ลบข้อมูลเดิมเพื่อให้ผลตรวจผ่าน ส่วนใบสมัครเดิม CAN-011 ที่พักไว้ยังไม่ดำเนินการกู้ทับ
