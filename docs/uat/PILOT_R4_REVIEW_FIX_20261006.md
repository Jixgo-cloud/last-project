# ผลแก้หน้าตรวจข้อสอบ R4 — 6 ตุลาคม 2026

แก้ R4 SIM 001 ที่หน้าปรนัยเปลี่ยนเป็นตรวจโค้ดทันทีหลังบันทึกคะแนน และแก้จุดโหลดรายชื่อทักษะบริษัทที่พบเพิ่มระหว่างตรวจซ้ำ การตรวจครั้งนี้เป็น AI ควบคุมเว็บด้วยบัญชี QA บริษัทและผู้สมัครเดิม ไม่ใช่ความคิดเห็นหรือการทดลองของคนจริง

## สิ่งที่แก้

หน้า `/company/assessments` เก็บชนิดข้อสอบ คำถาม ตัวเลือก คำตอบ และข้อมูลตรวจเดิมไว้ แล้วนำคะแนนและเหตุผลล่าสุดที่บริการบันทึกสำเร็จมาอัปเดต การตอบกลับแบบย่อของบริการจึงไม่ทำให้รายละเอียดคำตอบหาย ป้องกันการนำผลของรอบสอบหนึ่งไปแทนอีกคนที่เปิดดูอยู่

แยกผลการบันทึกจากการโหลดรายชื่อ หากคะแนนบันทึกสำเร็จแต่โหลดรายชื่อขัดข้อง หน้ายังคงแสดงคะแนนที่บันทึกแล้ว พร้อมแจ้งให้เปิดรายชื่อใหม่และไม่ต้องบันทึกคะแนนซ้ำ หากบริการปฏิเสธการบันทึกจะยังคงรายละเอียดเดิม

แก้เฉพาะหน้าเว็บ ไม่เปลี่ยนสูตรคะแนน สิทธิ์ หรือการเปิดเผยผลจากบริการ และไม่ต้องเปลี่ยนฐานข้อมูล

## จุดที่พบเพิ่ม: รายชื่อทักษะบริษัท

ชุดตรวจ CI รอบ 7e659f8 พบว่าหน้าข้อสอบบริษัทเรียก `/admin/skills` และถูกปฏิเสธ 403 ตรวจฟอร์มบนเว็บจริงก่อนแก้แล้วช่องทักษะมีเพียง “ไม่ระบุ” แม้มีรายการทักษะอยู่ในระบบ จัดเป็น **R4 SIM 002**

เปลี่ยนเป็นช่องทางเดิม `/skills` ที่หน้าลงงานของบริษัทใช้อยู่ ไม่เพิ่มสิทธิ์ผู้ดูแลให้บริษัท เพิ่มการตรวจหน้าจอว่าฟอร์มบริษัทมี JavaScript ให้เลือก และชุดตรวจต้องไม่มีคำขอ API ล้มเหลวที่ไม่ได้จำลองไว้ ตรวจฟอร์มแล้วกดยกเลิก ไม่บันทึกข้อสอบใหม่จากการตรวจนี้

## สถานะและสิ่งที่เหลือ

สถานะ R4 SIM 001 และ R4 SIM 002: **แก้แล้ว เผยแพร่แล้ว ตรวจซ้ำผ่าน ปิดข้อบกพร่องรอบนี้**

ทะเบียน UAT เดิมคง **ผ่าน 159 / ติดขัด 26 / ไม่ผ่าน 1 รวม 186 กรณี** ตรวจแล้วไฟล์ทะเบียนไม่เปลี่ยน การปิดข้อบกพร่องรอบเสริมนี้ไม่ได้ทำให้ข้อจำกัดเรื่องบัญชีใหม่ บริษัทที่สอง เอกสารจริง หรือใบสมัครที่หายผ่านไปด้วย

ขั้นต่อไปคือเตรียมงานและข้อสอบชุดใหม่เมื่อต้องการเริ่มทดลองโดยคนจริงตั้งแต่สมัคร เพราะ R4 มีประวัติแล้ว ใช้บัญชี QA เดิมได้ แต่ผลจำลองของ AI ไม่ทดแทนความคิดเห็นจากผู้ทดลองจริง
