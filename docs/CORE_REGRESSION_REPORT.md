# ผลตรวจการใช้งานหลักหลังเก็บกวาดโปรเจกต์

วันที่ 4 ตุลาคม 2026 — SmartCareer

ตรวจซ้ำหลังจัดระเบียบค่าตั้งระบบและขั้นตอนสร้างระบบแล้ว ผ่านทั้ง 16 รายการพร้อมตรวจอายุการเข้าสู่ระบบที่กำหนดเอง ดู [ผลตรวจรอบล่าสุด](RUNTIME_SETUP_REPORT.md) หลักฐานด้านล่างเป็นรอบหลังแก้หน้าสอบก่อนปรับค่าตั้งระบบ

ผลรอบสุดท้าย: ผ่านทั้ง 16 รายการ ไม่พบข้อผิดพลาดของหน้าเว็บหรือคำขอจากหน้าเว็บที่ล้มเหลวในขั้นตอนที่ทดสอบ

## ปัญหาที่พบและแก้แล้ว

1. คำตอบในแบบทดสอบไม่ถูกบันทึกอัตโนมัติ เพราะหน้าเว็บส่งข้อมูลไม่ครบและรูปแบบไม่ตรงกับระบบรับข้อมูล แก้ให้ส่งรหัสรอบสอบพร้อมคำตอบ และอ่านคำตอบเดิมกลับมาได้เมื่อเปิดหน้าใหม่
2. การบันทึกเหตุการณ์สลับหน้าจอล้มเหลว แก้ให้ส่งชื่อเหตุการณ์ เวลา และรายละเอียดตรงกับที่ระบบรับข้อมูล
3. การบันทึกอัตโนมัติยังทำงานระหว่างส่งข้อสอบ ทำให้มีคำขอถูกปฏิเสธหลังข้อสอบเสร็จแล้ว แก้ให้หยุดระหว่างส่งคำตอบหรือปิดรอบสอบ และบันทึกเฉพาะรอบที่กำลังทำอยู่

## สิ่งที่ตรวจผ่าน

| การใช้งาน | วิธีตรวจ |
| --- | --- |
| หน้าแรกและหน้าเข้าสู่ระบบ | เปิดในเบราว์เซอร์ |
| เข้าสู่ระบบผู้สมัคร บริษัท และผู้ดูแล | กรอกและกดจากหน้าเว็บ ตรวจสิทธิ์ที่ได้รับ |
| สร้างประกาศงาน เปิด–ปิดรับสมัคร และลบงาน | กดจากหน้าเว็บและตรวจข้อมูลที่บันทึก |
| สมัครงาน | กดจากหน้าเว็บ ตรวจใบสมัครและประวัติสถานะ |
| ยกเลิกและสมัครซ้ำ | เรียกระบบรับข้อมูล ตรวจว่ารอบสมัครเพิ่มเป็นรอบ 2 และหน้าเว็บแสดงงาน |
| บันทึกคำตอบอัตโนมัติและเปิดหน้าใหม่ | เลือกคำตอบ ตรวจข้อมูลที่เก็บ แล้วเปิดใหม่เพื่อยืนยันว่าคำตอบยังอยู่ |
| บันทึกเหตุการณ์ออกจากหน้าสอบ | จำลองเหตุการณ์ที่หน้าเว็บและตรวจข้อมูลที่เก็บ |
| ส่งแบบทดสอบเลือกตอบ | กดจากหน้าเว็บ ตรวจรอบสอบจบ คำตอบถูกต้อง และคะแนน 100% |
| ส่งโจทย์เขียนโปรแกรม | เปิดตัวแก้ไขและกดส่งจากหน้าเว็บ ตรวจคะแนน 100% และคำตอบที่เก็บ |
| บริษัทเปลี่ยนสถานะใบสมัคร | เรียกระบบรับข้อมูล ตรวจประวัติสถานะ การแจ้งเตือน และหน้าติดตามของผู้สมัคร |
| หน้าผู้ดูแล | เข้าสู่ระบบ เปิดหน้า และตรวจว่าระบบส่งข้อมูลภาพรวมได้ |

โจทย์เขียนโปรแกรมใช้ตัวอย่างบวกเลข 2 กับ 3 ได้ 5 โดยบริการ Judge0 ตอบผลสำเร็จ รายงานระบุเครื่องประมวลผลเป็น `Judge0-Isolated-Container` รอบนี้ไม่ได้ใช้ผลจำลองแทนการประมวลผล

ตรวจเพิ่มเติมผ่าน: การสร้างเว็บพร้อมใช้งาน การสร้างระบบหลังบ้าน การตรวจชนิดข้อมูลและรายการที่ไม่ได้ใช้ของเว็บกับระบบหลังบ้าน และ `git diff --check` การสร้างเว็บตั้งค่าให้ข้าม lint จึงไม่อ้างว่ารอบนี้ตรวจ lint ผ่าน

## การแยกข้อมูลทดสอบและหลักฐาน

สร้างฐานข้อมูลชั่วคราวสำหรับแต่ละรอบ ไม่เพิ่มหรือแก้บัญชี งาน หรือการสอบในฐานข้อมูลเดิม จำนวนผู้ใช้ งาน และรอบสอบในฐานข้อมูลเดิมก่อนและหลังรอบสุดท้ายเท่ากัน ลบฐานข้อมูลชั่วคราวและหยุดระบบทดสอบแล้ว โดยไม่แก้ไฟล์ `.env`

- ผลตรวจรอบสุดท้าย: [results.json](verification/core-regression-2026-10-04.json)
- ภาพหน้าจอและบันทึกระบบเก็บเฉพาะในเครื่องที่ตรวจ: `output/core-regression/smartcareer_regression_1791112992760/`
- สคริปต์ตรวจซ้ำ: [verify-core-regression.cjs](../scripts/verify-core-regression.cjs)

สคริปต์นี้ใช้ PostgreSQL ในเครื่องและ Microsoft Edge บน Windows ต้องสร้างเว็บและระบบหลังบ้านก่อน แล้วรัน `node scripts/verify-core-regression.cjs` ขณะพอร์ต 3000 และ 4000 ว่าง ต้องมีสิทธิ์สร้างฐานข้อมูลชั่วคราว และการตรวจโจทย์เขียนโปรแกรมเรียกบริการ Judge0 ตามค่าที่ตั้งไว้

## ขอบเขตที่ยังไม่ได้ตรวจ

ผลนี้ครอบคลุมเส้นทางหลักที่ระบุข้างต้น ยังไม่ได้ตรวจทุกหน้า ทุกกรณีผิดพลาด การลงทะเบียนใหม่ การเข้าสู่ระบบผ่านบริการภายนอก GitHub การประเมินคำตอบด้วย AI การนำเข้าคอร์ส หรือการติดตั้งบนเซิร์ฟเวอร์จริง รายการค่าตั้งระบบ ส่วนใช้ร่วมกัน และรูปแบบหน้าตาที่เหลือจากรายงานส่วนไม่ได้ใช้ยังเป็นงานถัดไป
